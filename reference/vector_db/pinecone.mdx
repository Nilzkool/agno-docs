:::caution Important Compatibility Note
We currently recommend using Pinecone client `v5.4.2` for optimal compatibility. Support for `v6.x.x` is actively being developed. Please install `pinecone==5.4.2`.
:::

The PineconeDb class provides a vector database implementation for Pinecone, supporting both synchronous and asynchronous operations for storing and retrieving vector embeddings, including hybrid search capabilities.
