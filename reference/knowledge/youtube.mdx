YouTubeKnowledgeBase is a knowledge base class that allows you to load, index, and query YouTube video transcripts. Under the hood, it uses `YouTubeReader` to fetch captions and transforms them into `Document` objects for vector storage and retrieval.

Key features:
- Supports synchronous loading via `load()` and asynchronous loading via `aload()`.
- Pass a configured reader to enable transcript chunking:

  ```python
  from agno.knowledge.youtube import YouTubeKnowledgeBase, YouTubeReader
  from agno.vectordb.qdrant import Qdrant

  kb = YouTubeKnowledgeBase(
      urls=["https://www.youtube.com/watch?v=XYZ"],
      vector_db=Qdrant(collection="youtube-videos", url="http://localhost:6333"),
      reader=YouTubeReader(chunk=True),  # enable chunking of transcripts
  )
  kb.load(recreate=True)
  ```

- After loading, you can query:
  ```python
  docs = kb.search("key topics in the video")
  ```
