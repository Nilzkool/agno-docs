---
title: PostgresMemoryDb
---

PostgresMemoryDb provides persistent storage for agent memories using PostgreSQL. Note: agno offers two implementations:

- v2: Modern implementation in agno.memory.v2.db.postgres (class PostgresMemoryDb) with JSONB support, timestamps, and automatic schema creation.
- v1 (legacy): Original implementation in agno.memory.db.postgres (class PgMemoryDb) without JSONB defaults.

By default, import the v2 implementation:

```python
from agno.memory.v2.db.postgres import PostgresMemoryDb
```
