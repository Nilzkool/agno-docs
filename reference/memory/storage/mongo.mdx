---
title: MongoMemoryDb
---

MongoMemoryDb provides persistent storage for agent memories using MongoDB. Note: agno offers two implementations:

- v2: Modern implementation in agno.memory.v2.db.mongodb with schema versioning (_version), updated_at timestamps, and optimistic locking.
- v1 (legacy): Original implementation in agno.memory.db.mongodb without versioning.

By default, import the v2 implementation:

```python
from agno.memory.v2.db.mongodb import MongoMemoryDb
```
