---
title: RedisMemoryDb
---

RedisMemoryDb provides persistent storage for agent memories using Redis. Note: agno offers two implementations:

- v2: Modern implementation in agno.memory.v2.db.redis with JSON serialization, created_at/updated_at timestamps, and namespaced keys.
- v1 (legacy): Original implementation in agno.memory.db.redis (not versioned separately).

By default, import the v2 implementation:

```python
from agno.memory.v2.db.redis import RedisMemoryDb
```
