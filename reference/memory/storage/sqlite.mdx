---
title: SqliteMemoryDb
---

SqliteMemoryDb provides lightweight, file-based or in-memory storage for agent memories using SQLite. Note: agno offers two implementations:

- v2: Modern implementation in agno.memory.v2.db.sqlite with automatic table creation, server_default timestamps, and persistent session management.
- v1 (legacy): Original implementation in agno.memory.db.sqlite without persistent session reuse.

By default, import the v2 implementation:

```python
from agno.memory.v2.db.sqlite import SqliteMemoryDb
```
