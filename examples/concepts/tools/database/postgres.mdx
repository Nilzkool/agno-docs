## Code

```python cookbook/tools/postgres_tools.py
from agno.agent import Agent
from agno.tools.postgres import PostgresTools

agent = Agent(
    tools=[
        PostgresTools(
            db_name="mydb",
            user="user",
            password="pass",
            host="localhost",
            port=5432,
            run_queries=True,
            inspect_queries=True,
            summarize_tables=True,
            export_tables=False,
            table_schema="public",
        )
    ],
    show_tool_calls=True,
    markdown=True,
)
agent.print_response("Show me all tables in the database")
```
