Agno supports using DynamoDB as a storage backend for Agents via the `DynamoDbStorage` class.

## Usage

Configure your AWS credentials in the environment or via the AWS CLI (no need to pass them explicitly):

```python
# cookbook/storage/dynamodb_storage/dynamodb_storage_for_agent.py
from agno.agent import Agent
from agno.storage.dynamodb import DynamoDbStorage
from agno.tools.duckduckgo import DuckDuckGoTools

# Create an agent with DynamoDB storage
agent = Agent(
    storage=DynamoDbStorage(
        table_name="agent_sessions",    # name of the DynamoDB table
        region_name="us-east-1"          # AWS region
    ),
    tools=[DuckDuckGoTools()],
    add_history_to_messages=True,
)

agent.print_response("How many people live in Canada?")
agent.print_response("What is their national anthem called?")
```
