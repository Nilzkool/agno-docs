Agno supports using DynamoDB as a storage backend for Teams via the `DynamoDbStorage` class.

## Usage

Configure your AWS credentials in the environment or via the AWS CLI (no need to pass them explicitly):

```python
# cookbook/storage/dynamodb_storage/dynamodb_storage_for_team.py
from typing import List

from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.storage.dynamodb import DynamoDbStorage
from agno.team import Team
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.hackernews import HackerNewsTools
from pydantic import BaseModel

class Article(BaseModel):
    title: str
    summary: str
    reference_links: List[str]

# Individual agents
hn_researcher = Agent(
    name="HackerNews Researcher",
    model=OpenAIChat("gpt-4o"),
    tools=[HackerNewsTools()],
)
web_searcher = Agent(
    name="Web Searcher",
    model=OpenAIChat("gpt-4o"),
    tools=[DuckDuckGoTools()],
    add_datetime_to_instructions=True,
)

# Team with DynamoDB storage
hn_team = Team(
    name="HackerNews Team",
    mode="coordinate",
    members=[hn_researcher, web_searcher],
    storage=DynamoDbStorage(
        table_name="team_sessions",  # DynamoDB table name
        region_name="us-east-1"      # AWS region
    ),
    instructions=[
        "First, search hackernews for what the user is asking about.",
        "Then, ask the web searcher to search for each story to get more information.",
        "Finally, provide a thoughtful and engaging summary.",
    ],
    response_model=Article,
    show_tool_calls=True,
    markdown=True,
    debug_mode=True,
    show_members_responses=True,
)

hn_team.print_response("Write an article about the top 2 stories on hackernews")
```
