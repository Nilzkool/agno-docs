## Code

```python cookbook/agent_concepts/knowledge/vector_dbs/milvus_db/milvus_db.py
from agno.agent import Agent
from agno.knowledge.pdf_url import PDFUrlKnowledgeBase
from agno.vectordb.milvus import Milvus

# Initialize Milvus (install via `pip install pymilvus`)
# Use `uri` to specify server or local file path
vector_db = Milvus(
    collection="recipes",
    uri="http://localhost:19530",  # use your Milvus server URI or local file path
)

# Create knowledge base
knowledge_base = PDFUrlKnowledgeBase(
    urls=["https://agno-public.s3.amazonaws.com/recipes/ThaiRecipes.pdf"],
    vector_db=vector_db,
)

knowledge_base.load(recreate=False)  # Comment out after first run

# Create and use the agent
agent = Agent(
    knowledge=knowledge_base,
    show_tool_calls=True,
    debug_mode=True,
)
agent.print_response("How to make Tom Kha Gai", markdown=True)
```
