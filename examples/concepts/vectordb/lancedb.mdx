## Code

```python cookbook/agent_concepts/knowledge/vector_dbs/lance_db/lance_db.py
from agno.agent import Agent
from agno.knowledge.pdf_url import PDFUrlKnowledgeBase
from agno.vectordb.lance_db import LanceDb

# Initialize LanceDB (install via `pip install lancedb`)
vector_db = LanceDb(
    table_name="recipes",
    uri="tmp/lancedb",  # change this path to store data elsewhere
)

# Create knowledge base
knowledge_base = PDFUrlKnowledgeBase(
    urls=["https://agno-public.s3.amazonaws.com/recipes/ThaiRecipes.pdf"],
    vector_db=vector_db,
)

knowledge_base.load(recreate=False)  # Comment out after first run

# Create and use the agent
agent = Agent(knowledge=knowledge_base, show_tool_calls=True, debug_mode=True)
agent.print_response("How to make Tom Kha Gai", markdown=True)
```
