## Code

```python
from agno.agent import Agent, RunResponse  # noqa
from agno.models.openai import OpenAIChat
import base64

# Provide the agent with the audio file and audio configuration and get result as text + audio
agent = Agent(
    model=OpenAIChat(
        id="gpt-4o-audio-preview",
        modalities=["text", "audio"],
        audio={"voice": "alloy", "format": "wav"},
    ),
    markdown=True,
)
response: RunResponse = agent.run("Tell me a 5 second scary story")

# Save the response audio to a file
if response.response_audio is not None and response.response_audio.content:
    audio_bytes = base64.b64decode(response.response_audio.content)
    with open("tmp/scary_story.wav", "wb") as f:
        f.write(audio_bytes)
```
