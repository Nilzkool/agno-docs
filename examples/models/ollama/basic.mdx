## Code

```python
from agno.agent import Agent, RunResponse  # noqa
from agno.models.ollama import Ollama

# Initialize an Ollama agent
agent = Agent(model=Ollama(id="llama3.1:8b"), markdown=True)

# Option A: Capture the response in a variable
def run_example():
    run = agent.run("Share a 2 sentence horror story")
    print(run.content)

# Option B: Print directly to the terminal
agent.print_response("Share a 2 sentence horror story")
```
