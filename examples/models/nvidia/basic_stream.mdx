## Code

```python
from agno.agent import Agent, RunResponse  # noqa
from agno.models.nvidia import Nvidia

# Initialize an agent for streaming responses
ingent = Agent(model=Nvidia(id="meta/llama-3.3-70b-instruct"), markdown=True)

# Option A: Iterate over streamed chunks
run_response = agent.run("Share a 2 sentence horror story", stream=True)
for chunk in run_response:
    print(chunk.content)

# Option B: Print directly to the terminal
agent.print_response("Share a 2 sentence horror story", stream=True)
```
