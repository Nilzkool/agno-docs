The `DockerContainer` class in Agno allows you to define and manage Docker containers as Python objects. This provides a structured and programmatic way to specify container configurations.

## `DockerContainer` Class

`DockerContainer` is a Pydantic model with the following configurable parameters:

```python
from typing import Any, Dict, List, Optional, Union

from agno.docker.resource.base import DockerResource


class DockerContainer(DockerResource):
    # The image to run.
    image: Optional[str] = None
    # The command to run in the container.
    command: Optional[Union[str, List]] = None
    # Enable auto-removal of the container when the container’s process exits. Default: True.
    # Note: If debug_mode is True, auto_remove is set to False.
    auto_remove: bool = True
    # Run container in the background and return a Container object. Default: True.
    detach: bool = True
    # The entrypoint for the container.
    entrypoint: Optional[Union[str, List]] = None
    # Environment variables to set inside the container.
    environment: Optional[Union[Dict[str, Any], List]] = None
    # List of additional group names and/or IDs that the container process will run as.
    group_add: Optional[List[Any]] = None
    # Specify a test to perform to check that the container is healthy.
    healthcheck: Optional[Dict[str, Any]] = None
    # Optional hostname for the container.
    hostname: Optional[str] = None
    # A dictionary of name-value labels (e.g. {"label1": "value1", "label2": "value2"})
    # or a list of names of labels to set with empty values (e.g. ["label1", "label2"]).
    labels: Optional[Dict[str, Any]] = None
    # Specification for mounts to be added to the container. More powerful alternative to volumes.
    # Each item in the list is a DockerContainerMount object which is then converted to a docker.types.Mount object.
    mounts: Optional[List[DockerContainerMount]] = None
    # Name of the network this container will be connected to at creation time.
    network: Optional[str] = None
    # Disable networking.
    network_disabled: Optional[str] = None
    # One of: bridge, none, container:<name|id>, host. Incompatible with network.
    network_mode: Optional[str] = None
    # Platform in the format os[/arch[/variant]].
    platform: Optional[str] = None
    # Ports to bind inside the container.
    # The keys of the dictionary are the ports to bind inside the container,
    # either as an integer or a string in the form port/protocol, where the protocol is either tcp, udp.
    # The values can be: port number (int), None (random host port), (address, port) tuple, or a list of integers.
    ports: Optional[Dict[str, Any]] = None
    # Remove the container when it has finished running. Default: True.
    # Note: If debug_mode is True, remove is set to False.
    remove: Optional[bool] = None
    # Restart the container when it exits. Configured as a dictionary with keys:
    # Name (str): One of on-failure, or always.
    # MaximumRetryCount (int): Number of times to restart the container on failure.
    # Example: {"Name": "on-failure", "MaximumRetryCount": 5}
    restart_policy: Optional[Dict[str, Any]] = None
    # Keep STDIN open even if not attached. Default: True.
    stdin_open: Optional[bool] = None
    # Return logs from STDOUT when detach=False. Default: True.
    stdout: Optional[bool] = None
    # Return logs from STDERR when detach=False. Default: True.
    stderr: Optional[bool] = None
    # Allocate a pseudo-TTY. Default: True.
    tty: Optional[bool] = None
    # Username or UID to run commands as inside the container.
    user: Optional[Union[str, int]] = None
    # A dictionary to configure volumes mounted inside the container.
    # The key is either the host path or a volume name, and the value is a dictionary with the keys:
    # bind - The path to mount the volume inside the container
    # mode - Either rw to mount the volume read/write, or ro to mount it read-only.
    # Example: {'/home/user1/': {'bind': '/mnt/vol2', 'mode': 'rw'}}
    volumes: Optional[Union[Dict[str, Any], List]] = None
    # Path to the working directory.
    working_dir: Optional[str] = None
    # A list of device requests for the container (e.g., for GPUs).
    devices: Optional[list] = None
```

## Example Usage

```python resources.py
from agno.docker.resource.container import DockerContainer

whoami_container = DockerContainer(
    name='my-whoami-app',
    image='traefik/whoami',
    ports={'80': 8080}, # Map container port 80 to host port 8080
    remove=True, # Automatically remove the container when it exits
    auto_remove=True, # Enable auto-removal for cleanup
    detach=True, # Run in the background
    devices=['/dev/nvidia0:/dev/nvidia0:rwm'] # Example: for GPU access
)
```
