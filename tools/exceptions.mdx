---
title: Exceptions
---

If after a tool call we need to "retry" the model with a different set of instructions, stop the agent, or handle internal errors, we can raise one of the following exceptions:

- `RetryAgentRun`: Exception raised when a tool call should be retried.
- `StopAgentRun`: Exception raised when an agent should stop executing entirely.
- `AgentRunException`: Generic exception for agent run failures (base class for retries/stops).
- `RunCancelledException`: Exception raised when a run is cancelled by the user.
- `AgnoError`: Exception raised when an internal error occurs (includes `message` and `status_code`).
- `ModelProviderError`: Exception raised when a model provider returns an error.
- `ModelRateLimitError`: Exception raised specifically for rate limit errors from the model provider (status code 429).

This example shows how to use the `RetryAgentRun` exception to retry the agent with additional instructions.

```python retry_in_tool_call.py
from agno.agent import Agent
from agno.exceptions import RetryAgentRun
from agno.models.openai import OpenAIChat
from agno.utils.log import logger


def add_item(agent: Agent, item: str) -> str:
    """Add an item to the shopping list."""
    agent.session_state["shopping_list"].append(item)
    len_shopping_list = len(agent.session_state["shopping_list"] )
    if len_shopping_list < 3:
        # Retry until at least 3 items are added
        raise RetryAgentRun(
            f"Shopping list is: {agent.session_state['shopping_list']}. "
            + f"Add {3 - len_shopping_list} more items." 
        )

    logger.info(f"The shopping list is now: {agent.session_state['shopping_list']}")
    return f"The shopping list is now: {agent.session_state['shopping_list']}"


agent = Agent(
    model=OpenAIChat(id="gpt-4o-mini"),
    # Initialize the session state with an empty shopping list
    session_state={"shopping_list": []},
    tools=[add_item],
    markdown=True,
)
agent.print_response("Add milk", stream=True)
print(f"Final session state: {agent.session_state}")
```

<Tip>
Make sure to set `AGNO_DEBUG=true` (or `AGNO_DEBUG=True`) to see the debug logs.
</Tip>
