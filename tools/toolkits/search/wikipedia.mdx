---
title: Wikipedia
---

**WikipediaTools** enable an Agent to search Wikipedia or read website content, and optionally add it to a knowledge base.

## Prerequisites

Install the `wikipedia` library:

```shell
pip install -U wikipedia
```

## Example

```python
from agno.agent import Agent
from agno.tools.wikipedia import WikipediaTools

agent = Agent(tools=[WikipediaTools()], show_tool_calls=True, markdown=True)
agent.print_response("Search Wikipedia for 'artificial intelligence'")
```

## Toolkit Params

| Name             | Type                     | Default | Description                                                                                                        |
| ---------------- | ------------------------ | ------- | ------------------------------------------------------------------------------------------------------------------ |
| `knowledge_base` | `WikipediaKnowledgeBase` | -       | Optional base to which results are added when using the update function.                                          |

## Toolkit Functions

| Function Name                                | Description                                                                                               |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `search_wikipedia_and_update_knowledge_base` | Searches Wikipedia for a topic, loads into the provided knowledge base, and returns JSON of document list. |
| `search_wikipedia`                           | Searches Wikipedia for a query and returns a single summary document as JSON.                              |
