---

**TavilyTools** enable an Agent to search the web using the Tavily API.

## Prerequisites

Install the `tavily-python` library and set your Tavily API key:

```shell
pip install -U tavily-python
export TAVILY_API_KEY=***
```

## Example

```python
from agno.agent import Agent
from agno.tools.tavily import TavilyTools

agent = Agent(
    tools=[TavilyTools()],
    show_tool_calls=True,
    markdown=True
)
agent.print_response("Search Tavily for 'language models'")
```

## Toolkit Params

| Parameter            | Type                           | Default      | Description                                                                                  |
| -------------------- | ------------------------------ | ------------ | -------------------------------------------------------------------------------------------- |
| `api_key`            | `str`                          | -            | Tavily API key. Falls back to TAVILY_API_KEY env var.                                        |
| `search`             | `bool`                         | `True`       | Enable web search.                                                                           |
| `max_tokens`         | `int`                          | `6000`       | Max tokens for search results.                                                              |
| `include_answer`     | `bool`                         | `True`       | Include AI-generated summary.                                                               |
| `search_depth`       | `Literal['basic','advanced']`  | `advanced`   | Search depth mode.                                                                          |
| `format`             | `Literal['json','markdown']`   | `markdown`   | Output format.                                                                              |
| `use_search_context` | `bool`                         | `False`      | Use Tavily's context API instead of basic search.                                           |

## Toolkit Functions

| Function                  | Description                                                                                                                               |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `web_search_using_tavily` | Searches the web for a query. Params: `query`, `max_results`. Returns JSON or markdown of results with titles, URLs, content, scores. |
| `web_search_with_tavily`  | Uses Tavily's context API. Params: `query`. Returns JSON with contextual search results.                                                |
