---

**SerpApiTools** enable an Agent to search Google and YouTube via the SerpApi service.

## Prerequisites

Install the `google-search-results` library and set your SerpApi API key:

```shell
pip install -U google-search-results
export SERPAPI_API_KEY=***
```

## Example

```python
from agno.agent import Agent
from agno.tools.serpapi import SerpApiTools

agent = Agent(tools=[SerpApiTools()], show_tool_calls=True, markdown=True)
agent.print_response("What's happening in the USA?")
```

## Toolkit Params

| Parameter        | Type   | Default | Description                                                 |
| ---------------- | ------ | ------- | ----------------------------------------------------------- |
| `api_key`        | `str`  | -       | Your SerpApi API key.                                       |
| `search_youtube` | `bool` | `False` | Enable YouTube search functionality.                        |

## Toolkit Functions

| Function         | Description                                              |
| ---------------- | -------------------------------------------------------- |
| `search_google`  | Searches Google for a query. Returns JSON of filtered keys.   |
| `search_youtube` | Searches YouTube for a query. Returns JSON of video data. |
