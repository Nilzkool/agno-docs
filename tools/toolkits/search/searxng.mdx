**Searxng** enables an Agent to perform web searches, image searches, news searches, and more using a SearxNG instance.

## Example

```python
from agno.agent import Agent
from agno.tools.searxng import Searxng

# Initialize SearxNG with your instance URL
searxng = Searxng(
    host="http://localhost:53153",
    engines=[],
    fixed_max_results=5,
    news=True,
    science=True
)

# Create an agent with SearxNG
agent = Agent(tools=[searxng], show_tool_calls=True, markdown=True)

agent.print_response(
    "Please search for information about artificial intelligence "
    "and summarize the key points from the top results."
)
```

## Toolkit Params

| Parameter           | Type        | Default | Description                                                        |
| ------------------- | ----------- | ------- | ------------------------------------------------------------------ |
| `host`              | `str`       | -       | The base URL of your SearxNG instance.                             |
| `engines`           | `List[str]` | `[]`    | A list of search engines to query.                                 |
| `fixed_max_results` | `int`       | `None`  | Optional maximum number of results to always return.               |
| `images`            | `bool`      | `False` | Enable image search.                                               |
| `it`                | `bool`      | `False` | Enable IT category search.                                         |
| `map`               | `bool`      | `False` | Enable map category search.                                        |
| `music`             | `bool`      | `False` | Enable music category search.                                      |
| `news`              | `bool`      | `False` | Enable news category search.                                       |
| `science`           | `bool`      | `False` | Enable science category search.                                    |
| `videos`            | `bool`      | `False` | Enable video category search.                                      |

## Toolkit Functions

| Function         | Description                                                                                                                 |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `search`         | Performs a general web search. Params: `query`, `max_results` (default 5). Returns JSON string of results.                 |
| `image_search`   | Searches images. Params: `query`, `max_results` (default 5). Returns JSON string of image results.                         |
| `it_search`      | Searches IT-related content. Params: `query`, `max_results`. Returns JSON string.                                           |
| `map_search`     | Searches map data. Params: `query`, `max_results`. Returns JSON string.                                                    |
| `music_search`   | Searches music-related content. Params: `query`, `max_results`. Returns JSON string.                                        |
| `news_search`    | Searches news. Params: `query`, `max_results`. Returns JSON string.                                                        |
| `science_search` | Searches science content. Params: `query`, `max_results`. Returns JSON string.                                            |
| `video_search`   | Searches videos. Params: `query`, `max_results`. Returns JSON string.                                                     |
