**ShellTools** enable an Agent to interact with the shell to run commands.

## Usage

Import and add the ShellTools to your Agent. Optionally specify a `base_dir` where commands will be executed:

```python
from agno.agent import Agent
from agno.tools.shell import ShellTools

# Create ShellTools with optional base_dir
shell_tools = ShellTools(base_dir="/path/to/directory")

agent = Agent(tools=[shell_tools], show_tool_calls=True)
# Send a command, e.g. list directory contents
agent.print_response("ls -la", markdown=True)
```

The `run_shell_command` function accepts:
- `args` (List[str]): The command and its arguments, e.g. ["ls", "-la"].
- `tail` (int, default=100): Number of lines of the output to return.

## Functions in Toolkit

| Function            | Signature                             | Description                                           |
| ------------------- | ------------------------------------- | ----------------------------------------------------- |
| `run_shell_command` | `(args: List[str], tail: int = 100) -> str` | Runs a shell command and returns the output or error. |
