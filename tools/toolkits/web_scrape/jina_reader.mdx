title: Jina Reader
---

**JinaReaderTools** enable an Agent to perform web search tasks using Jina.

## Prerequisites

The following example requires the `jina` library.

```shell
pip install -U jina
```

## Example

The following agent will use Jina API to summarize the content of https://github.com/agno-agi:

```python cookbook/tools/jinareader_tools.py
from agno.agent import Agent
from agno.tools.jina import JinaReaderTools

agent = Agent(
    tools=[JinaReaderTools()],
    debug_mode=True,
    show_tool_calls=True,
)
agent.print_response("Summarize: https://github.com/agno-agi", markdown=True)
```

## Toolkit Params

| Parameter            | Type    | Default               | Description                                                                |
| -------------------- | ------- | --------------------- | -------------------------------------------------------------------------- |
| `api_key`            | `str`   | `None`                | The API key for authentication purposes, retrieved from the environment.   |
| `base_url`           | `str`   | `https://r.jina.ai/`  | The base URL of the Jina Reader API.                                       |
| `search_url`         | `str`   | `https://s.jina.ai/`  | The URL used for search queries in the Jina Reader API.                    |
| `max_content_length` | `int`   | `10000`               | The maximum length of content (in characters) returned before truncation.   |
| `timeout`            | `int`   | `None`                | Optional timeout (seconds) for API requests.                               |
| `read_url`           | `bool`  | `True`                | Whether to register the `read_url` function for fetching URL content.      |
| `search_query`       | `bool`  | `False`               | Whether to register the `search_query` function for performing searches.    |

## Toolkit Functions

| Function       | Description                                                                                                                                                                                            |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `read_url`     | Reads a URL and returns truncated content using the Jina Reader API. Raises an error message on failure.                                                                                                |
| `search_query` | Performs a web search query using the Jina Reader API and returns truncated results. Raises an error message on failure.                                                                                 |
