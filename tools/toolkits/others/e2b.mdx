title: E2B
---

**E2BTools** enable an Agent to execute code in a secure sandboxed environment with support for Python, file operations, and web server capabilities.

## Prerequisites

The E2B tools require the `e2b_code_interpreter` package and an API key:

```shell
pip install e2b_code_interpreter
```

```shell
export E2B_API_KEY=your_api_key
```

## Example

The following example demonstrates how to create an agent that can run Python code in a secure sandbox:

```python
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.tools.e2b import E2BTools

e2b_tools = E2BTools(
    timeout=600,  # 10 minutes timeout
)

agent = Agent(
    name="Code Execution Sandbox",
    agent_id="e2b-sandbox",
    model=OpenAIChat(id="gpt-4o"),
    tools=[e2b_tools],
    markdown=True,
    show_tool_calls=True,
)

# Example: Generate Fibonacci numbers
er_agent = agent.print_response(
    "Write Python code to generate the first 10 Fibonacci numbers and calculate their sum and average"
)
```

## Toolkit Params

| Parameter            | Type   | Default | Description                                              |
| -------------------- | ------ | ------- | -------------------------------------------------------- |
| `api_key`            | `str`  | `None`  | E2B API key (env var `E2B_API_KEY`).                     |
| `run_code`           | `bool` | `True`  | Register the `run_python_code` function.                |
| `upload_file`        | `bool` | `True`  | Register the `upload_file` function.                    |
| `download_result`    | `bool` | `True`  | Register result download functions.                     |
| `filesystem`         | `bool` | `False` | Register filesystem operations.                          |
| `internet_access`    | `bool` | `False` | Register internet access functions.                      |
| `sandbox_management` | `bool` | `False` | Register sandbox management functions.                   |
| `timeout`            | `int`  | `300`   | Sandbox timeout (seconds).                               |
| `sandbox_options`    | `dict` | `None`  | Options passed to the Sandbox constructor.               |
| `command_execution`  | `bool` | `False` | Register shell command execution functions.              |

## Toolkit Functions

### Code Execution

| Function           | Description                              |
| ------------------ | ---------------------------------------- |
| `run_python_code`  | Execute Python code in the E2B sandbox. |

### File Operations

| Function                     | Description                                              |
| ---------------------------- | -------------------------------------------------------- |
| `upload_file`                | Upload a file to the sandbox.                            |
| `download_png_result`        | Add a PNG result as an ImageArtifact.                    |
| `download_chart_data`        | Extract chart data and save as JSON/artifact.            |
| `download_file_from_sandbox` | Download a file from sandbox to local system.            |

### Filesystem Operations

| Function             | Description                                    |
| -------------------- | ---------------------------------------------- |
| `list_files`         | List files and directories in the sandbox.     |
| `read_file_content`  | Read text or binary files from the sandbox.    |
| `write_file_content` | Write text content to a sandbox file.         |
| `watch_directory`    | Watch for changes in a sandbox directory.      |

### Command Execution

| Function                | Description                                     |
| ----------------------- | ----------------------------------------------- |
| `run_command`           | Run a shell command in the sandbox.             |
| `stream_command`        | Stream command stdout/stderr.                   |
| `run_background_command`| Run a command in the background.                |
| `kill_background_command` | Terminate a background command.                |

### Internet Access

| Function         | Description                                    |
| ---------------- | ---------------------------------------------- |
| `get_public_url` | Get a public URL for a sandbox service.        |
| `run_server`     | Start a server and return its public URL.      |

### Sandbox Management

| Function                  | Description                              |
| ------------------------- | ---------------------------------------- |
| `set_sandbox_timeout`     | Update sandbox timeout.                  |
| `get_sandbox_status`      | Retrieve current sandbox status.         |
| `shutdown_sandbox`        | Terminate the sandbox immediately.       |
| `list_running_sandboxes`  | List all active sandboxes.               |
