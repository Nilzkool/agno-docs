---title: ModelsLabs---## PrerequisitesYou need to install the `requests` library.```bashpip install requests```Set the `MODELS_LAB_API_KEY` environment variable.```bashexport MODELS_LAB_API_KEY=****```## ExampleThe following agent will use ModelsLabs to generate a video based on a text prompt.```python cookbook/tools/models_labs_tools.pyfrom agno.agent import Agentfrom agno.tools.models_labs import ModelsLabTools# Create an Agent with the ModelsLabs toolagent = Agent(tools=[ModelsLabTools()], name="ModelsLabs Agent")agent.print_response("Generate a video of a beautiful sunset over the ocean", markdown=True)```## Toolkit Params| Parameter             | Type   | Default                                           | Description `api_key`             | `str`  | `None`                                            | The ModelsLab API key for authentication                                   || `wait_for_completion` | `bool` |
