---title: OpenBB---**OpenBBTools** enable an Agent to provide information about stocks and companies.```python cookbook/tools/openbb_tools.pyfrom agno.agent import Agentfrom agno.tools.openbb import OpenBBToolsagent = Agent(tools=[OpenBBTools()], debug_mode=True, show_tool_calls=True)# Example usage showing stock analysisagent.print_response(    "Get me the current stock price and key information for Apple (AAPL)")# Example showing market analysisagent.print_response(    "What are the top gainers in the market today?")# Example showing economic indicatorsagent.print_response(    "Show me the latest GDP growth rate and inflation numbers for the US")```## Toolkit Params| Parameter          | Type                                            | Default    | Description
