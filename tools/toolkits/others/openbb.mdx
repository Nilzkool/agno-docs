**OpenBBTools** enable an Agent to provide information about stocks and companies using the OpenBB library.

## Prerequisites

```bash
pip install 'openbb'
```

Set your API token if required:

```shell
export OPENBB_PAT=your_pat_here
```

## Example

```python cookbook/tools/openbb_tools.py
from agno.agent import Agent
from agno.tools.openbb import OpenBBTools

agent = Agent(
    tools=[OpenBBTools(
        provider="yfinance",
        stock_price=True,
        search_symbols=True,
        company_news=True,
        company_profile=True,
        price_targets=True,
    )],
    debug_mode=True,
    show_tool_calls=True,
)

# Fetch current stock price and company info for Apple
agent.print_response("Get me the current stock price and key information for Apple (AAPL)")
```

## Toolkit Params

| Parameter         | Type        | Default    | Description                                                                      |
| ----------------- | ----------- | ---------- | -------------------------------------------------------------------------------- |
| `obb`             | `Any`       | `openbb_app` | OpenBB application object (for testing/injection).                               |
| `openbb_pat`      | `str`       | `None`     | Personal access token for OpenBB authentication.                                 |
| `provider`        | `str`       | `yfinance` | Data provider (`benzinga`, `fmp`, `intrinio`, `polygon`, `tiingo`, `tmx`, `yfinance`). |
| `stock_price`     | `bool`      | `True`     | Enable `get_stock_price` tool.                                                   |
| `search_symbols`  | `bool`      | `False`    | Enable `search_company_symbol` tool.                                             |
| `company_news`    | `bool`      | `False`    | Enable `get_company_news` tool.                                                  |
| `company_profile` | `bool`      | `False`    | Enable `get_company_profile` tool.                                               |
| `price_targets`   | `bool`      | `False`    | Enable `get_price_targets` tool.                                                 |

## Toolkit Functions

| Function                | Description                                                                   |
| ----------------------- | ----------------------------------------------------------------------------- |
| `get_stock_price`       | Get current stock price for a symbol or comma-separated list of symbols.    |
| `search_company_symbol` | Search for ticker symbols of a company.                                       |
| `get_price_targets`     | Fetch consensus price targets and recommendations.                            |
| `get_company_news`      | Get latest news items for a stock symbol or list of symbols.                 |
| `get_company_profile`   | Get company profile and overview for given symbol(s).                         |
