---

**OpenBBTools** enable an Agent to fetch stock and company data via the OpenBB SDK.

```python
from agno.agent import Agent
from agno.tools.openbb import OpenBBTools

# Create an agent with OpenBBTools (default enables get_stock_price)
agent = Agent(
    tools=[OpenBBTools(openbb_pat="YOUR_OPENBB_PAT", provider="yfinance")],
    markdown=True,
    show_tool_calls=True,
)

# Get current stock price
agent.print_response("Get the current stock price for AAPL")

# Search for a company symbol
agent.print_response("Search for ticker symbols for Tesla")

# Get company news
agent.print_response("Fetch the latest 5 news stories for MSFT")
```

## Toolkit Params

| Parameter         | Type     | Default       | Description                                                                                   |
| ----------------- | -------- | ------------- | --------------------------------------------------------------------------------------------- |
| `obb`             | Any      | `None`        | OpenBB SDK module instance; if not provided, uses `import openbb.obb as openbb_app` by default |
| `openbb_pat`      | `str`    | `None`        | OpenBB Personal Access Token; falls back to `OPENBB_PAT` environment variable if set          |
| `provider`        | `str`    | `"yfinance"`| Data provider to use. Options: `"benzinga"`, `"fmp"`, `"intrinio"`, `"polygon"`, `"tiingo"`, `"tmx"`, `"yfinance"` |
| `stock_price`     | `bool`   | `True`        | Enable the `get_stock_price` function                                                        |
| `search_symbols`  | `bool`   | `False`       | Enable the `search_company_symbol` function                                                  |
| `company_news`    | `bool`   | `False`       | Enable the `get_company_news` function                                                       |
| `company_profile` | `bool`   | `False`       | Enable the `get_company_profile` function                                                    |
| `price_targets`   | `bool`   | `False`       | Enable the `get_price_targets` function                                                      |

## Toolkit Functions

| Function                | Description                                                                                                    |
| ----------------------- | -------------------------------------------------------------------------------------------------------------- |
| `get_stock_price`       | Get the current stock price for a symbol or comma-separated list of symbols.                                   |
| `search_company_symbol` | Search for ticker symbols by company name.                                                                     |
| `get_price_targets`     | Get consensus price targets and recommendations for a symbol or list of symbols.                              |
| `get_company_news`      | Fetch recent news stories for a symbol with optional `limit` parameter (default 10).                          |
| `get_company_profile`   | Retrieve company profile and overview data for a symbol or list of symbols.                                   |
