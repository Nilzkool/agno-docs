# Getting Started with Agno Agents 🚀This guide walks through the basics of building Agents with Agno.Each example builds on the previous one, introducing new concepts and capabilities progressively. Examples contain detailed comments, example prompts, and required dependencies.## SetupCreate a virtual environment:```bashpython3 -m venv .venvsource .venv/bin/activate```Install the required dependencies:```bashpip install openai duckduckgo-search yfinance lancedb tantivy pypdf requests exa-py newspaper4k lxml_html_clean sqlalchemy agno```Export your OpenAI API key:```bashexport OPENAI_API_KEY=your_api_key```## Examples Overview### 1.
