| Parameter                         | Type                                    | Default    | Description                                                                                       |
| --------------------------------- | --------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------- |
| `id`                              | `str`                                   | —          | ID of the model to use.                                                                            |
| `name`                            | `Optional[str]`                         | `None`     | Name for this Model. Not sent to the Model API.                                                    |
| `provider`                        | `Optional[str]`                         | `None`     | Provider for this Model. Not sent to the Model API.                                                |
| `response_format`                 | `Optional[Any]`                         | `None`     | Format of the response (set by Agent based on response_model or JSON mode).                        |
| `structured_outputs`              | `bool`                                  | `False`    | Whether to generate structured outputs from this model.                                            |
| `supports_native_structured_outputs` | `bool`                              | `False`    | True if the model supports native structured outputs (e.g. OpenAI).                                 |
| `supports_json_schema_outputs`    | `bool`                                  | `False`    | True if the model supports JSON-schema based outputs.                                              |
| `tool_choice`                     | `Optional[Union[str, Dict[str, Any]]]`  | `None`     | Controls which function, if any, the model will call.                                              |
| `show_tool_calls`                 | `Optional[bool]`                        | `None`     | If True, include function/tool-call records in the response.                                       |
| `tool_call_limit`                 | `Optional[int]`                         | `None`     | Maximum number of tool calls allowed during a response.                                            |
| `_tools`                          | `Optional[List[Dict]]`                  | `None`     | Internal list of tool metadata sent to the model.                                                  |
| `_functions`                      | `Optional[Dict[str, Function]]`         | `None`     | Internal mapping of function definitions extracted from tools.                                      |
| `_function_call_stack`            | `Optional[List[FunctionCall]]`          | `None`     | Internal stack of function calls executed during a response.                                       |
| `system_prompt`                   | `Optional[str]`                         | `None`     | System prompt text from the model provider added to the Agent’s prompt chain.                      |
| `instructions`                    | `Optional[List[str]]`                   | `None`     | Provider-supplied instructions added to the Agent’s prompt chain.                                  |
| `tool_message_role`               | `str`                                   | `"tool"` | Role assigned to tool-call messages in the conversation.                                           |
| `assistant_message_role`          | `str`                                   | `"assistant"` | Role assigned to the assistant messages in the conversation.                                    |
