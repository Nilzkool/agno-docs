| Parameter                         | Type                                    | Default    | Description                                                      |
| --------------------------------- | --------------------------------------- | ---------- | ---------------------------------------------------------------- |
| id                                | string                                  | *required* | Model identifier (e.g., `"gpt-4"`).                              |
| name                              | string                                  | None       | Friendly name for this model. Not sent to the provider API.      |
| provider                          | string                                  | None       | Provider name for this model. Not sent to the provider API.      |
| response_format                   | any                                     | None       | Structured output format (e.g., JSON schema or Pydantic model).  |
| structured_outputs                | boolean                                 | False      | Whether to enable structured outputs on this model.              |
| supports_native_structured_outputs| boolean                                 | False      | True if the model natively supports structured JSON responses.   |
| supports_json_schema_outputs      | boolean                                 | False      | True if the model supports JSON Schema–based responses.          |
| tool_choice                       | string or object                        | None       | Controls function invocation: `"none"`, `"auto"`, or specific. |
| show_tool_calls                   | boolean                                 | None       | If True, include tool call details in model responses.           |
| tool_call_limit                   | integer                                 | None       | Maximum number of allowed function/tool calls.                   |
| _tools                            | array of objects                        | None       | Internal list of tool definitions sent to the model.             |
| _functions                        | object                                  | None       | Internal map of available functions for tool invocation.         |
| _function_call_stack              | array                                   | None       | Internal execution stack of function calls.                      |
| system_prompt                     | string                                  | None       | System prompt inserted before user messages.                     |
| instructions                      | array of strings                        | None       | Additional instructions added to model prompts.                  |
| tool_message_role                 | string                                  | "tool"     | Role name for function/tool call messages.                       |
| assistant_message_role            | string                                  | "assistant"| Role name for assistant messages returned by the model.          |
