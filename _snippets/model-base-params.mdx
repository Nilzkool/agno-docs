| Parameter                          | Type                                   | Default    | Description                                                                 |
| ---------------------------------- | -------------------------------------- | ---------- | --------------------------------------------------------------------------- |
| `id`                               | `str`                                  | –          | ID of the model to use. Alias: “model”.                                      |
| `name`                             | `Optional[str]`                        | `None`     | Name for this Model. Not sent to the Model API.                              |
| `provider`                         | `Optional[str]`                        | `None`     | Provider for this Model. Not sent to the Model API.                          |
| `response_format`                  | `Optional[Any]`                        | `None`     | Format to instruct JSON object or schema for model responses.                |
| `structured_outputs`               | `bool`                                 | `False`    | Whether the Model generates structured outputs (e.g. JSON objects).          |
| `supports_native_structured_outputs` | `bool`                               | `False`    | True if the Model natively supports structured outputs.                      |
| `supports_json_schema_outputs`     | `bool`                                 | `False`    | True if the Model supports JSON schema–based structured outputs mode.        |
| `tool_choice`                      | `Optional[Union[str, Dict[str,Any]]]`  | `None`     | Controls which (if any) tool is called by the Model.                         |
| `show_tool_calls`                  | `Optional[bool]`                       | `None`     | If True, shows function call entries in the response.                        |
| `tool_call_limit`                  | `Optional[int]`                        | `None`     | Maximum number of tool calls allowed.                                        |
| `_tools`                           | `Optional[List[Dict[str,Any]]]`        | `None`     | List of tool/function definitions sent to the Model.                         |
| `_functions`                       | `Optional[Dict[str,Function]]`         | `None`     | Functions extracted from the tools.                                          |
| `_function_call_stack`             | `Optional[List[FunctionCall]]`         | `None`     | Stack of executed function calls.                                            |
| `system_prompt`                    | `Optional[str]`                        | `None`     | System prompt from the Model added to the Agent/Team.                        |
| `instructions`                     | `Optional[List[str]]`                  | `None`     | Instructions from the Model added to the Agent/Team prompt.                  |
| `tool_message_role`                | `str`                                  | `"tool"` | Role for messages that come from tool calls.                                 |
| `assistant_message_role`           | `str`                                  | `"assistant"` | Role for assistant messages from the Model.                                  |
