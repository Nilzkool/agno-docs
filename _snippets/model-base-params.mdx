| Parameter                                   | Type                                            | Default    | Description                                                    |
| ----------------------------------------- | ----------------------------------------------- | ---------- | -------------------------------------------------------------- |
| `id`                                      | `str`                                           | -          | ID of the model to use. Alias: "model"                         |
| `name`                                    | `Optional[str]`                                 | `None`     | Name for this Model. Not sent to the Model API.                |
| `provider`                                | `Optional[str]`                                 | `None`     | Provider for this Model. Not sent to the Model API.            |
| `response_format`                         | `Optional[Any]`                                 | `None`     | Specifies the format of the response.                          |
| `structured_outputs`                      | `bool`                                          | `False`    | Determines whether to use structured outputs with this Model.    |
| `supports_native_structured_outputs`      | `bool`                                          | `False`    | True if the model supports native structured outputs.          |
| `supports_json_schema_outputs`            | `bool`                                          | `False`    | True if the model requires a JSON schema for structured outputs. |
| `tool_choice`                             | `Optional[Union[str, Dict[str, Any]]]`            | `None`     | Controls which (if any) function is called by the model.       |
| `show_tool_calls`                         | `Optional[bool]`                                 | `None`     | If True, shows function calls in the response.                 |
| `tool_call_limit`                         | `Optional[int]`                                  | `None`     | Maximum number of tool calls allowed.                          |
| `_functions`                              | `Optional[Dict[str, Function]]`                  | `None`     | Internal. Functions extracted from the tools.                  |
| `_function_call_stack`                    | `Optional[List[FunctionCall]]`                   | `None`     | Internal. Keeps track of the function call stack.              |
| `system_prompt`                           | `Optional[str]`                                 | `None`     | The system prompt obtained from the model and added to the Agent.|
| `instructions`                            | `Optional[List[str]]`                           | `None`     | Instructions from the model to guide the Agent's behavior.       |
