| Parameter                              | Type                                   | Default      | Description                                                       |
|----------------------------------------|----------------------------------------|--------------|-------------------------------------------------------------------|
| `id`                                   | `str`                                  | -            | ID of the model to use.                                          |
| `name`                                 | `Optional[str]`                        | `None`       | Name for this Model. Not sent to the Model API.                  |
| `provider`                             | `Optional[str]`                        | `None`       | Provider for this Model. Not sent to the Model API.               |
| `response_format`                      | `Optional[Any]`                        | `None`       | Format guidance sent to the Model provider.                      |
| `structured_outputs`                   | `bool`                                 | `False`      | Whether to generate structured outputs from this Model.          |
| `supports_native_structured_outputs`   | `bool`                                 | `False`      | Model supports native structured outputs.                        |
| `supports_json_schema_outputs`         | `bool`                                 | `False`      | Model supports JSON schema outputs.                              |
| `tool_choice`                          | `Optional[Union[str, Dict[str, Any]]]` | `None`       | Controls function/tool invocation behavior.                       |
| `show_tool_calls`                      | `Optional[bool]`                       | `None`       | If True, shows tool/function call records.                       |
| `tool_call_limit`                      | `Optional[int]`                        | `None`       | Maximum number of tool calls allowed.                            |
| `_tools`                               | `Optional[List[Dict]]`                 | `None`       | Tools provided to the Model.                                      |
| `_functions`                           | `Optional[Dict[str, Function]]`        | `None`       | Functions extracted from the provided tools.                      |
| `_function_call_stack`                 | `Optional[List[FunctionCall]]`         | `None`       | Stack of executed function calls.                                 |
| `system_prompt`                        | `Optional[str]`                        | `None`       | System prompt text added to the Agent.                            |
| `instructions`                         | `Optional[List[str]]`                  | `None`       | Instructions added to the Agent context.                          |
| `tool_message_role`                    | `str`                                  | `"tool"`   | Role used for messages from tool executions.                     |
| `assistant_message_role`               | `str`                                  | `"assistant"` | Role used for assistant messages.                              |
