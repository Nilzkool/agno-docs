| Parameter                      | Type                                    | Default | Description                                                  |
| ------------------------------ | --------------------------------------- | ------- | ------------------------------------------------------------ |
| id                             | `str`                                   | `-`     | ID of the model to use.                                      |
| name                           | `Optional[str]`                         | `None`  | Name for this Model (not sent to API).                      |
| provider                       | `Optional[str]`                         | `None`  | Provider for this Model (not sent to API).                  |
| response_format                | `Optional[Any]`                         | `None`  | Format for model responses (e.g. JSON schema or Pydantic).  |
| structured_outputs             | `bool`                                  | `False` | Whether to use native structured outputs.                   |
| supports_native_structured_outputs | `bool`                             | `False` | True if model supports structured outputs natively.         |
| supports_json_schema_outputs   | `bool`                                  | `False` | True if model supports JSON schema outputs.                  |
| tool_choice                    | `Optional[Union[str, Dict[str, Any]]]`  | `None`  | Controls which function is called by the model.              |
| show_tool_calls                | `Optional[bool]`                        | `None`  | If True, include function calls in responses.               |
| tool_call_limit                | `Optional[int]`                         | `None`  | Maximum number of allowed function calls.                    |
| _tools                         | `Optional[List[Dict]]`                  | `None`  | Internal: tools available to the model.                      |
| _functions                     | `Optional[Dict[str, Function]]`         | `None`  | Internal: functions extracted from tools.                    |
| _function_call_stack           | `Optional[List[FunctionCall]]`          | `None`  | Internal: executed function call history.                   |
| system_prompt                  | `Optional[str]`                         | `None`  | Internal: system prompt from the model.                      |
| instructions                   | `Optional[List[str]]`                   | `None`  | Internal: instructions from the model.                       |
| tool_message_role              | `str`                                   | `"tool"` | Role assigned to tool messages.                            |
| assistant_message_role         | `str`                                   | `"assistant"` | Role assigned to assistant messages.                       |
