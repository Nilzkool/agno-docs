| Parameter                           | Type                                   | Default    | Description                                                                 |
| ----------------------------------- | -------------------------------------- | ---------- | --------------------------------------------------------------------------- |
| `id`                                | `str`                                  | -          | ID of the model to use.                                                     |
| `name`                              | `Optional[str]`                        | `None`     | Name for this Model. Not sent to the Model API.                              |
| `provider`                          | `Optional[str]`                        | `None`     | Provider for this Model. Not sent to the Model API.                          |
| `response_format`                   | `Optional[Any]`                        | `None`     | Response format or JSON schema configuration for structured outputs.         |
| `structured_outputs`                | `bool`                                 | `False`    | Whether to generate structured outputs.                                      |
| `supports_native_structured_outputs`| `bool`                                 | `False`    | Model supports native structured outputs (e.g., OpenAI).                     |
| `supports_json_schema_outputs`      | `bool`                                 | `False`    | Model requires a JSON schema for structured outputs.                         |
| `tool_choice`                       | `Optional[Union[str, Dict[str, Any]]]` | `None`     | Controls which function calls are allowed: "none", "auto", or specific.  |
| `show_tool_calls`                   | `Optional[bool]`                       | `None`     | If True, show tool/function calls in model responses.                       |
| `tool_call_limit`                   | `Optional[int]`                        | `None`     | Maximum number of tool/function calls allowed per response.                 |
| `_tools`                            | `Optional[List[Dict]]`                 | `None`     | Raw tool definitions sent to the model.                                       |
| `_functions`                        | `Optional[Dict[str, Function]]`        | `None`     | Available Function objects extracted from `_tools`.                          |
| `_function_call_stack`              | `Optional[List[FunctionCall]]`         | `None`     | History of executed function calls in this session.                          |
| `system_prompt`                     | `Optional[str]`                        | `None`     | System prompt injected into agent messages.                                  |
| `instructions`                      | `Optional[List[str]]`                  | `None`     | Default instructions provided by the model.                                  |
| `tool_message_role`                 | `str`                                  | `"tool"` | Role assigned to tool/function messages in the conversation.                |
| `assistant_message_role`            | `str`                                  | `"assistant"` | Role assigned to assistant-generated messages.                            |
