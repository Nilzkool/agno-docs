| Parameter                              | Type                                   | Default    | Description                                                        |
|----------------------------------------|----------------------------------------|------------|--------------------------------------------------------------------|
| `id`                                   | `str`                                  | -          | ID of the model to use.                                            |
| `name`                                 | `Optional[str]`                        | `None`     | Name for this Model. Not sent to the Model API.                    |
| `provider`                             | `Optional[str]`                        | `None`     | Provider for this Model. Not sent to the Model API.                |
| `response_format`                      | `Optional[Any]`                        | `None`     | Format for the model response (e.g. JSON schema or Pydantic model).|
| `structured_outputs`                   | `bool`                                 | `False`    | Whether to output structured data from this model.                 |
| `supports_native_structured_outputs`   | `bool`                                 | `False`    | Model supports native structured outputs (e.g. OpenAI).            |
| `supports_json_schema_outputs`         | `bool`                                 | `False`    | Model requires JSON schema for structured outputs.                |
| `tool_choice`                          | `Optional[Union[str, Dict[str, Any]]]` | `None`     | Controls which function/tool the model may call by default.        |
| `show_tool_calls`                      | `Optional[bool]`                       | `None`     | When true, includes function call metadata in the model response. |
| `tool_call_limit`                      | `Optional[int]`                        | `None`     | Maximum number of function/tool calls allowed.                     |
| `_tools`                               | `Optional[List[Dict]]`                 | `None`     | Definitions of tools sent to the model.                            |
| `_functions`                           | `Optional[Dict[str, Function]]`        | `None`     | Executable functions extracted from the tools.                     |
| `system_prompt`                        | `Optional[str]`                        | `None`     | Default system prompt injected into conversations.                 |
| `instructions`                         | `Optional[List[str]]`                  | `None`     | Provider-specific instructions added to the model.                 |
| `tool_message_role`                    | `str`                                  | `"tool"` | Role used for messages produced by tools.                          |
| `assistant_message_role`               | `str`                                  | `"assistant"` | Role used for assistant messages.                                |
