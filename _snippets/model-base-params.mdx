| Parameter                   | Type                                   | Default | Description                                                                                  |
|-----------------------------|----------------------------------------|---------|----------------------------------------------------------------------------------------------|
| `id`                        | `str`                                  | —       | ID of the model to use.                                                                      |
| `name`                      | `Optional[str]`                        | `None`  | Name for this Model. Not sent to the model API.                                              |
| `provider`                  | `Optional[str]`                        | `None`  | Provider for this Model. Not sent to the model API.                                          |
| `response_format`           | `Optional[Any]`                        | `None`  | Format to use when requesting structured or JSON schema outputs.                             |
| `structured_outputs`        | `bool`                                 | `False` | Whether to format the model's response according to a structured output schema.             |
| `supports_native_structured_outputs` | `bool`                     | `False` | Whether the model natively supports structured outputs without a JSON schema.                |
| `supports_json_schema_outputs`     | `bool`                     | `False` | Whether the model can generate responses based on a provided JSON schema.                    |
| `tool_choice`               | `Optional[Union[str, Dict[str, Any]]]` | `None`  | Controls whether the model invokes function calls: "none", "auto", or a specific function. |
| `show_tool_calls`           | `Optional[bool]`                       | `None`  | If `True`, include tool call records in the model's response.                                |
| `tool_call_limit`           | `Optional[int]`                        | `None`  | Maximum number of function calls allowed per response.                                       |
| `_tools`                    | `Optional[List[Dict]]`                 | `None`  | Internal list of tools/functions definitions sent to the model API.                          |
| `_functions`                | `Optional[Dict[str, Function]]`        | `None`  | Internal map of function name to callable for executing tool calls.                          |
| `_function_call_stack`      | `Optional[List[FunctionCall]]`         | `None`  | Internal stack tracking executed function calls.                                            |
| `system_prompt`             | `Optional[str]`                        | `None`  | System prompt snippet injected into the agent's message history.                             |
| `instructions`              | `Optional[List[str]]`                  | `None`  | Additional instructions injected into the agent's prompt.                                    |
| `tool_message_role`         | `str`                                  | `"tool"` | Role assigned to messages generated by tools/functions.                                     |
| `assistant_message_role`    | `str`                                  | `"assistant"` | Role assigned to assistant model messages.                                               |
