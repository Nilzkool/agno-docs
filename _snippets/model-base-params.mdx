| Parameter                          | Type                                   | Default    | Description                                                                                          |
| ---------------------------------- | -------------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------- |
| `id`                               | `str`                                  | -          | ID of the model to use.                                                                              |
| `name`                             | `Optional[str]`                        | `None`     | Optional human-readable name for this Model (not sent to the provider API).                         |
| `provider`                         | `Optional[str]`                        | `None`     | Provider identifier for this Model (default derived from name/id).                                   |
| `response_format`                  | `Optional[Any]`                        | `None`     | Hint for model output format (e.g. JSON object schema) set by Agent based on `response_model`.      |
| `structured_outputs`               | `bool`                                 | `False`    | Whether the Model should generate structured outputs.                                                |
| `supports_native_structured_outputs` | `bool`                               | `False`    | True if the provider supports native structured outputs (e.g. OpenAI).                               |
| `supports_json_schema_outputs`     | `bool`                                 | `False`    | True if the provider accepts a JSON schema for structured outputs.                                   |
| `tool_choice`                      | `Optional[Union[str, Dict[str, Any]]]` | `None`     | Mode for function calls: `"none"`, `"auto"`, or a specific function selector.                  |
| `show_tool_calls`                  | `Optional[bool]`                       | `None`     | If True, include tool call events in the model response.                                            |
| `tool_call_limit`                  | `Optional[int]`                        | `None`     | Maximum number of function/tool calls allowed per response.                                          |
| `_tools`                           | `Optional[List[Dict[str, Any]]]`       | `None`     | Serialized tool definitions sent to the provider.                                                    |
| `_functions`                       | `Optional[Dict[str, Function]]`        | `None`     | Local Function objects extracted from tools (not sent to provider).                                  |
| `_function_call_stack`             | `Optional[List[FunctionCall]]`         | `None`     | History of FunctionCall executions.                                                                  |
| `system_prompt`                    | `Optional[str]`                        | `None`     | Optional system prompt snippet contributed by the Model.                                            |
| `instructions`                     | `Optional[List[str]]`                  | `None`     | Optional instruction text from the Model for use in Agent system messages.                          |
| `tool_message_role`                | `str`                                  | `"tool"` | Role name used for messages originating from tool/function calls.                                    |
| `assistant_message_role`           | `str`                                  | `"assistant"` | Role name used for assistant/model messages.                                                       |
