| Parameter                     | Type                                   | Default    | Description                                                    |
| ----------------------------- | -------------------------------------- | ---------- | -------------------------------------------------------------- |
| `id`                          | `str`                                  | -          | ID of the model to use. Alias: "model"                         |
| `name`                        | `Optional[str]`                        | `None`     | Name for this Model. Not sent to the Model API.                |
| `provider`                    | `Optional[str]`                        | `None`     | Provider for this Model. Not sent to the Model API.            |
| `response_format`             | `Optional[Any]`                        | `None`     | Format of the response.                                        |
| `structured_outputs`          | `bool`                                 | `False`    | Whether to generate structured outputs from this Model.        |
| `supports_native_structured_outputs` | `bool`                          | `False`    | True if the Model supports structured outputs natively (e.g., OpenAI). |
| `supports_json_schema_outputs` | `bool`                                | `False`    | True if the Model requires a JSON schema for structured outputs (e.g., LMStudio). |
| `tool_choice`                 | `Optional[Union[str, Dict[str, Any]]]` | `None`     | Controls which (if any) function is called by the model.       |
| `show_tool_calls`             | `Optional[bool]`                       | `None`     | If True, shows function calls in the response.                 |
| `tool_call_limit`             | `Optional[int]`                        | `None`     | Maximum number of tool calls allowed.                          |
| `system_prompt`               | `Optional[str]`                        | `None`     | System prompt from the model to be passed to the Agent.        |
| `instructions`                | `Optional[List[str]]`                  | `None`     | Instructions from the model to be passed to the Agent.         |
| `tool_message_role`           | `str`                                  | `"tool"`   | The role to assign to tool messages in the conversation.       |
| `assistant_message_role`      | `str`                                  | `"assistant"` | The role to assign to assistant messages in the conversation.  |
