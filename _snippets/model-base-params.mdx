## Model Base Parameters

Model instances accept the following parameters:

| Parameter                          | Type                                   | Default    | Description                                                 |
|------------------------------------|----------------------------------------|------------|-------------------------------------------------------------|
| `id`                               | `str`                                  | –          | Identifier of the model to use.                             |
| `name`                             | `Optional[str]`                        | `None`     | Human-readable name for this model (not sent in API calls).|
| `provider`                         | `Optional[str]`                        | `None`     | Model provider (not sent in API calls).                     |
| `response_format`                  | `Optional[Any]`                        | `None`     | Format specification for structured outputs.                |
| `structured_outputs`               | `bool`                                 | `False`    | Enable native structured outputs if supported.             |
| `supports_native_structured_outputs`| `bool`                                | `False`    | True if model natively supports structured outputs.         |
| `supports_json_schema_outputs`     | `bool`                                 | `False`    | True if model requires JSON‐schema for outputs.             |
| `tool_choice`                      | `Optional[Union[str, Dict[str, Any]]]` | `None`     | Controls function/tool calling mode (`none`, `auto`, etc.).|
| `show_tool_calls`                  | `Optional[bool]`                       | `None`     | If true, include tool‐call metadata in responses.          |
| `tool_call_limit`                  | `Optional[int]`                        | `None`     | Maximum number of tool calls allowed per response.         |
| `_tools`                           | `Optional[List[Dict]]`                 | `None`     | Raw tool definitions sent to the model.                     |
| `_functions`                       | `Optional[Dict[str, Function]]`        | `None`     | Parsed Function definitions.                               |
| `_function_call_stack`             | `Optional[List[FunctionCall]]`         | `None`     | History of executed function calls.                        |
| `system_prompt`                    | `Optional[str]`                        | `None`     | Base system prompt injected into each conversation.         |
| `instructions`                     | `Optional[List[str]]`                  | `None`     | Additional instructions in the prompt.                     |
| `tool_message_role`                | `str`                                  | `"tool"` | Role label assigned to tool‐generated messages.             |
| `assistant_message_role`           | `str`                                  | `"assistant"` | Role label assigned to assistant messages.             |
