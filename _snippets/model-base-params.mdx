| Parameter                               | Type                                   | Default    | Description                                                         |
| --------------------------------------- | -------------------------------------- | ---------- | ------------------------------------------------------------------- |
| `id`                                    | `str`                                  | -          | ID of the model to use.                                             |
| `name`                                  | `Optional[str]`                        | `None`     | Name for this Model. Not sent to the Model API.                     |
| `provider`                              | `Optional[str]`                        | `None`     | Provider for this Model. Not sent to the Model API.                 |
| `response_format`                       | `Optional[Any]`                        | `None`     | Response format to request from the model (e.g. JSON schema).       |
| `structured_outputs`                    | `bool`                                 | `False`    | Whether to generate structured outputs.                             |
| `supports_native_structured_outputs`    | `bool`                                 | `False`    | Whether the model supports structured outputs natively.             |
| `supports_json_schema_outputs`          | `bool`                                 | `False`    | Whether the model supports JSON schema outputs.                     |
| `tool_choice`                           | `Optional[Union[str, Dict[str, Any]]]` | `None`     | Controls function-call behavior: `"none"`, `"auto"`, or custom. |
| `show_tool_calls`                       | `Optional[bool]`                       | `None`     | If `True`, include function calls in the response.                  |
| `tool_call_limit`                       | `Optional[int]`                        | `None`     | Maximum number of function calls allowed.                           |
| `_tools`                                | `Optional[List[Dict]]`                 | `None`     | Tools available to the model (function definitions).                |
| `_functions`                            | `Optional[Dict[str, Function]]`        | `None`     | Extracted `Function` objects for tool execution.                    |
| `_function_call_stack`                  | `Optional[List[FunctionCall]]`         | `None`     | History of function calls executed by the model.                    |
| `system_prompt`                         | `Optional[str]`                        | `None`     | Provider-level system prompt appended to agent messages.            |
| `instructions`                          | `Optional[List[str]]`                  | `None`     | Provider-level instructions appended to agent messages.             |
