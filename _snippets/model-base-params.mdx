| Parameter                         | Type                                   | Default    | Description                                                        |
| --------------------------------- | -------------------------------------- | ---------- | ------------------------------------------------------------------ |
| `id`                              | `str`                                  | `-`        | ID of the model to use.                                            |
| `name`                            | `Optional[str]`                        | `None`     | Name for this Model. Not sent to the Model API.                    |
| `provider`                        | `Optional[str]`                        | `None`     | Provider for this Model. Not sent to the Model API.                |
| `response_format`                 | `Optional[Any]`                        | `None`     | Format for the response (e.g. JSON schema).                        |
| `structured_outputs`              | `bool`                                 | `False`    | Enable native structured outputs from the model.                   |
| `supports_native_structured_outputs` | `bool`                              | `False`    | Whether the model supports native structured outputs.              |
| `supports_json_schema_outputs`    | `bool`                                 | `False`    | Whether the model requires a JSON schema for structured outputs.   |
| `tool_choice`                     | `Optional[Union[str, Dict[str, Any]]]` | `None`     | Controls which function is called (`"none"`, `"auto"`, or specific). |
| `show_tool_calls`                 | `Optional[bool]`                       | `None`     | Show function calls in the model response.                         |
| `tool_call_limit`                 | `Optional[int]`                        | `None`     | Maximum number of function calls allowed.                          |
| `tools`                           | `Optional[List[Dict]]`                 | `None`     | Tools provided to the model (converted to function definitions).   |
| `_functions`                      | `Optional[Dict[str, Function]]`        | `None`     | Extracted function definitions available to the model.             |
| `_function_call_stack`            | `Optional[List[FunctionCall]]`         | `None`     | Stack of executed function calls.                                  |
| `system_prompt`                   | `Optional[str]`                        | `None`     | System prompt injected by the model.                               |
| `instructions`                    | `Optional[List[str]]`                  | `None`     | Instructions provided by the model.                                |
| `tool_message_role`               | `str`                                  | `"tool"` | Role to assign to tool messages.                                   |
| `assistant_message_role`          | `str`                                  | `"assistant"` | Role to assign to assistant messages.                           |
