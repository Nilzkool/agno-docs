| Parameter | Type | Default | Description |
| --------- | ---- | ------- | ----------- |
| `collection` | `str` | Required | Name of the Milvus collection to store vectors and metadata |
| `embedder` | `Optional[Embedder]` | `OpenAIEmbedder()` | Embedder instance to generate embeddings |
| `distance` | `Distance` | `Distance.cosine` | Distance metric to use for similarity search |
| `uri` | `str` | `"http://localhost:19530"` | URI of the Milvus server. If a local file (e.g., `./milvus.db`), uses Milvus Lite. For self-hosted Milvus, use server address. For Zilliz Cloud, use Public Endpoint. |
| `token` | `Optional[str]` | `None` | Token for authentication. Use "username:password" for self-hosted Milvus with auth, or API key for Zilliz Cloud. |
