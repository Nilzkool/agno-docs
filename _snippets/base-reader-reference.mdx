| Parameter            | Type                  | Default                | Description                                    |
|----------------------|-----------------------|------------------------|------------------------------------------------|
| `chunk_size`         | `int`                 | `5000`                 | Number of characters per chunk                 |
| `overlap`            | `int`                 | `0`                    | Number of characters to overlap between chunks |
| `chunking_strategy`  | `ChunkingStrategy`    | `FixedSizeChunking`    | Strategy class used for splitting documents    |
