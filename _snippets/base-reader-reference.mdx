| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `chunk` | `bool` | `True` | Whether to chunk the documents |
| `chunk_size` | `int` | `1000` | Size of each chunk when chunking is enabled |
| `overlap` | `int` | `0` | The number of characters to overlap between chunks |
| `chunking_strategy` | `Optional[ChunkingStrategy]` | `FixedSizeChunking` | Strategy class used for chunking documents |
