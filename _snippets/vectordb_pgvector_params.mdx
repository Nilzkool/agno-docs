| Parameter             | Type                   | Default                 | Description                                                                            |
| --------------------- | ---------------------- | ----------------------- | -------------------------------------------------------------------------------------- |
| `table_name`          | `str`                  | Required                | The name of the table to use.                                                          |

| `db_url`              | `Optional[str]`        | `None`                  | The database URL to connect to.                                                        |
