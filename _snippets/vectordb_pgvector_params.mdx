| Parameter             | Type                             | Default        | Description                                                     |
|-----------------------|----------------------------------|----------------|-----------------------------------------------------------------|
| `table_name`          | `str`                            | -              | The name of the table to use.                                   |
| `schema`              | `str`                            | `"ai"`        | The schema to use.                                              |
| `db_url`              | `str`                            | `None`         | The database URL to connect to.                                 |
| `db_engine`           | `Engine`                         | `None`         | The database engine to use.                                     |
| `embedder`            | `Embedder`                       | `None`         | The embedder to use (defaults to OpenAIEmbedder if not provided)|
| `search_type`         | `SearchType`                     | `vector`       | The search type to use.                                         |
| `vector_index`        | `Union[Ivfflat, HNSW]`           | `HNSW()`       | The vector index to use.                                        |
| `distance`            | `Distance`                       | `Distance.cosine` | The distance metric for comparisons                            |
| `prefix_match`        | `bool`                           | `False`        | Whether to use prefix matching for full-text search            |
| `vector_score_weight` | `float`                          | `0.5`          | Weight for vector similarity in hybrid search (0 ≤ value ≤ 1)   |
| `content_language`    | `str`                            | `"english"`  | The content language to use for text search                    |
| `schema_version`      | `int`                            | `1`            | The schema version to use.                                      |
| `auto_upgrade_schema` | `bool`                           | `False`        | Whether to automatically upgrade the schema on init             |
| `reranker`            | `Optional[Reranker]`             | `None`         | Reranker instance to refine search results                     |
