| Parameter                          | Type                                  | Default                  | Description                                                                                            |
| ---------------------------------- | ------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------ |
| `id`                               | `str`                                 | `"gemini-2.0-flash-exp"` | The specific model ID used for generating responses.                                                   |
| `name`                             | `str`                                 | `"Gemini"`               | The name identifier for the agent.                                                                     |
| `provider`                         | `str`                                 | `"Google"`               | The provider of the model. When `vertexai` is `True`, it uses the Vertex AI API.                       |
| `supports_native_structured_outputs` | `bool`                                | `True`                   | Whether the Model supports native structured outputs.                                                  |
| `function_declarations`            | `Optional[List[Any]]`                 | `None`                   | A list of function declarations that the model can utilize during the response generation process.     |
| `generation_config`                | `Optional[Any]`                       | `None`                   | Configuration settings for the generation process, such as parameters for controlling output behavior. |
| `safety_settings`                  | `Optional[List[Any]]`                 | `None`                   | Settings related to safety measures, ensuring the generation of appropriate and safe content.          |
| `generative_model_kwargs`          | `Optional[Dict[str, Any]]`           | `None`                   | Additional parameters for the generative model requests.                                               |
| `search`                           | `bool`                                | `False`                  | If `True`, enables Google Search tool for grounding responses.                                         |
| `grounding`                        | `bool`                                | `False`                  | If `True`, enables Google Search Retrieval for grounding responses, disabling other tools.             |
| `grounding_dynamic_threshold`      | `Optional[float]`                     | `None`                   | Threshold for dynamic retrieval in Google Search grounding.                                            |
| `temperature`                      | `Optional[float]`                     | `None`                   | Controls randomness in the model's output.                                                             |
| `top_p`                            | `Optional[float]`                     | `None`                   | Controls diversity via nucleus sampling.                                                               |
| `top_k`                            | `Optional[int]`                       | `None`                   | The number of top-k tokens to consider for sampling.                                                   |
| `max_output_tokens`                | `Optional[int]`                       | `None`                   | The maximum number of tokens to generate in the response.                                              |
| `stop_sequences`                   | `Optional[list[str]]`                 | `None`                   | Sequences at which the model should stop generating further tokens.                                    |
| `logprobs`                         | `Optional[bool]`                      | `None`                   | Whether to include log probabilities in the response.                                                  |
| `presence_penalty`                 | `Optional[float]`                     | `None`                   | Penalizes new tokens based on whether they appear in the text so far.                                  |
| `frequency_penalty`                | `Optional[float]`                     | `None`                   | Penalizes new tokens based on their frequency in the text so far.                                      |
| `seed`                             | `Optional[int]`                       | `None`                   | A seed for deterministic sampling.                                                                     |
| `response_modalities`              | `Optional[list[str]]`                 | `None`                   | List of modalities in which the model should respond (e.g., "Text", "Image").                          |
| `speech_config`                    | `Optional[dict[str, Any]]`            | `None`                   | Speech-specific configuration for audio responses.                                                     |
| `cached_content`                   | `Optional[Any]`                       | `None`                   | Cached content to be used for responses.                                                               |
| `request_params`                   | `Optional[Dict[str, Any]]`            | `None`                   | Additional parameters to include in the request.                                                       |
| `api_key`                          | `Optional[str]`                       | `None`                   | The API key for authenticating with Google (optional when using Vertex AI).                            |
| `vertexai`                         | `bool`                                | `False`                  | If `True`, use the Vertex AI API instead of the Google Generative AI API.                              |
| `project_id`                       | `Optional[str]`                       | `None`                   | Google Cloud project ID to use for Vertex AI.                                                          |
| `location`                         | `Optional[str]`                       | `None`                   | Google Cloud location (region) to use for Vertex AI.                                                   |
| `client_params`                    | `Optional[Dict[str, Any]]`            | `None`                   | Additional parameters for client configuration.                                                        |
| `client`                           | `Optional[google.genai.Client]`       | `None`                   | A pre-configured instance of the Gemini client.                                                        |
