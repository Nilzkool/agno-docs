| Parameter           | Type                   | Default              | Description                                        |
| ------------------- | ---------------------- | -------------------- | -------------------------------------------------- |
| `reader`            | `Optional[Reader]`     | `None`               | Reader to read the documents                       |
| `vector_db`         | `Optional<VectorDb>`   | `None`               | Vector DB to store the knowledge base              |
| `chunking_strategy` | `ChunkingStrategy`     | `FixedSizeChunking()`| Chunking strategy to split documents               |
| `num_documents`     | `int`                  | `5`                  | Number of relevant documents to return on search   |
| `optimize_on`       | `Optional[int]`        | `1000`               | Threshold to trigger vector DB optimization        |
