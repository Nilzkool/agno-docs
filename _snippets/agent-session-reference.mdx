| Parameter       | Type               | Default     | Description                                                    |
|-----------------|--------------------|-------------|----------------------------------------------------------------|
| session_id      | str                | Required    | Session UUID                                                   |
| user_id         | Optional[str]      | None        | ID of the user interacting with this session                   |
| team_session_id | Optional[str]      | None        | ID of the parent team session (if applicable)                  |
| memory          | Optional[Dict[str, Any]] | None  | Stored memory state                                             |
| session_data    | Optional[Dict[str, Any]] | None  | Session metadata: name, state, media (images/audio/video)       |
| extra_data      | Optional[Dict[str, Any]] | None  | Arbitrary extra data saved with this session                    |
| created_at      | Optional[int]      | None        | Unix timestamp when the session was created                    |
| updated_at      | Optional[int]      | None        | Unix timestamp when the session was last updated               |
| agent_id        | Optional[str]      | None        | ID of the Agent associated with this session                   |
| agent_data      | Optional[Dict[str, Any]] | None  | Agent metadata: id, name, model                                |
