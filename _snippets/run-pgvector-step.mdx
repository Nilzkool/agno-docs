<Step title="Run PgVector">
```bash
# Run a pgvector container mapping host port 5432 to container port 5432
# Use the official agnohq/pgvector image (tag 16)
docker run -d \
  -e POSTGRES_DB=ai \
  -e POSTGRES_USER=ai \
  -e POSTGRES_PASSWORD=ai \
  -e PGDATA=/var/lib/postgresql/data/pgdata \
  -v pgvolume:/var/lib/postgresql/data \
  -p 5432:5432 \
  --name pgvector \
  agnohq/pgvector:16
```
</Step>
