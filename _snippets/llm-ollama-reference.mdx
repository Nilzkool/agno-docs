| Parameter         | Type                                     | Default       | Description                                                                                            |
|-------------------|------------------------------------------|---------------|--------------------------------------------------------------------------------------------------------|
| name              | `str`                                     | `"Ollama"`   | Client name for this model class.                                                                     |
| id                | `str`                                     | `"llama3.1"` | ID of the Ollama model to use.                                                                        |
| host              | `Optional[str]`                           | `None`        | Host address for the Ollama API.                                                                      |
| timeout           | `Optional[Any]`                           | `None`        | Request timeout for the Ollama client.                                                                |
| format            | `Optional[Any]`                           | `None`        | Response format (e.g., JSON) when structured_outputs is enabled.                                       |
| options           | `Optional[Any]`                           | `None`        | Additional model parameters such as `temperature`, `top_p`.                                           |
| keep_alive        | `Optional[Union[float, str]]`             | `None`        | Duration to keep the model loaded in memory after the request.                                         |
| client_params     | `Optional[Dict[str, Any]]`                | `None`        | Extra `{key: value}` params passed when initializing the `OllamaClient`.                                 |
| request_params    | `Optional[Dict[str, Any]]`                | `None`        | Additional request kwargs sent with each `chat` call.                                                 |
| tools             | `Optional[List[Dict]]`                    | `None`        | List of tools/functions definitions included in the request payload.                                   |
| response_format   | `Optional[Any]`                           | `None`        | Structured output schema or Pydantic model for JSON responses.                                        |
| structured_outputs| `bool`                                    | `False`       | Whether to request native structured outputs from the model.                                          |
| show_tool_calls   | `Optional[bool]`                          | `None`        | If True, include tool call info in the responses.                                                     |
| tool_choice       | `Optional[Union[str, Dict[str, Any]]]`    | `None`        | Controls function-call behavior: “none”, “auto”, or specify a function.                                |
| tool_call_limit   | `Optional[int]`                           | `None`        | Maximum number of function/tool calls allowed.                                                        |
