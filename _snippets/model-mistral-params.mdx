| Parameter           | Type                                                      | Default                  | Description                                                                                     |
| ------------------- | --------------------------------------------------------- | ------------------------ | ----------------------------------------------------------------------------------------------- |
| `id`                | `str`                                                     | `"mistral-large-latest"` | The ID of the Mistral model to use.                                                            |
| `name`              | `str`                                                     | `"MistralChat"`          | The display name of the model.                                                                  |
| `provider`          | `str`                                                     | `"Mistral"`              | The model provider.                                                                             |
| `temperature`       | `Optional[float]`                                         | `None`                   | Controls randomness in output generation.                                                       |
| `max_tokens`        | `Optional[int]`                                           | `None`                   | Maximum number of tokens to generate.                                                          |
| `top_p`             | `Optional[float]`                                         | `None`                   | Controls diversity of output (nucleus sampling).                                                |
| `random_seed`       | `Optional[int]`                                           | `None`                   | Seed for deterministic sampling.                                                               |
| `safe_mode`         | `bool`                                                    | `False`                  | Enables content filtering on the model side.                                                   |
| `safe_prompt`       | `bool`                                                    | `False`                  | Applies safe-mode filtering to prompts before sending.                                          |
| `response_format`   | `Optional[Union[Dict[str, Any], ChatCompletionResponse]]` | `None`                   | Specifies a structured or custom response format.                                              |
| `request_params`    | `Optional[Dict[str, Any]]`                                | `None`                   | Additional request parameters to include in the API call.                                       |
| `api_key`           | `Optional[str]`                                           | `None`                   | Your Mistral API key (or set via `MISTRAL_API_KEY` env var).                                    |
| `endpoint`          | `Optional[str]`                                           | `None`                   | Custom API endpoint URL (if not using the default).                                             |
| `max_retries`       | `Optional[int]`                                           | `None`                   | Maximum number of retry attempts for failed requests.                                           |
| `timeout`           | `Optional[int]`                                           | `None`                   | Timeout for the API request, in seconds.                                                        |
| `client_params`     | `Optional[Dict[str, Any]]`                                | `None`                   | Extra parameters passed when constructing the `MistralClient`.                                  |
| `mistral_client`    | `Optional[MistralClient]`                                 | `None`                   | Provide a pre-configured `MistralClient` instance to bypass default initialization.             |
