## Anthropic Claude Parameters

When using `agno.models.anthropic.Claude` (or its AWS Bedrock variant), you can configure:

| Parameter          | Type                         | Default                         | Description                                    |
|--------------------|------------------------------|---------------------------------|------------------------------------------------|
| `id`               | `str`                        | `"claude-3-5-sonnet-20241022"`| Anthropic Claude model identifier.             |
| `name`             | `str`                        | `"Claude"`                    | Human-readable model name.                     |
| `provider`         | `str`                        | `"Anthropic"`                 | Model provider label.                          |
| `max_tokens`       | `Optional[int]`              | `4096`                          | Max tokens to generate in completion.         |
| `thinking`         | `Optional[Dict[str, Any]]`   | `None`                          | Claude’s internal thinking/control parameters. |
| `temperature`      | `Optional[float]`            | `None`                          | Sampling temperature.                          |
| `stop_sequences`   | `Optional[List[str]]`        | `None`                          | Sequences to end generation.                   |
| `top_p`            | `Optional[float]`            | `None`                          | Nucleus sampling probability threshold.        |
| `top_k`            | `Optional[int]`              | `None`                          | Token‐level top-k sampling.                    |
| `request_params`   | `Optional[Dict[str, Any]]`   | `None`                          | Any extra request parameters.                  |
| `api_key`          | `Optional[str]`              | `None`                          | Anthropic API key (env `ANTHROPIC_API_KEY`).    |
| `client_params`    | `Optional[Dict[str, Any]]`   | `None`                          | Extra client configuration.                    |
| `client`           | `Optional[AnthropicClient]`  | `None`                          | Synchronic Anthropic client instance.          |
| `async_client`     | `Optional[AsyncAnthropicClient]` | `None`                     | Asynchronous Anthropic client instance.       |
