| Parameter                             | Type                             | Default  | Description                                                      |
|---------------------------------------|----------------------------------|----------|------------------------------------------------------------------|
| id                                    | str                              | –        | Identifier of the model to use                                   |
| name                                  | Optional[str]                    | None     | Display name for this model (not sent to API)                   |
| provider                              | Optional[str]                    | None     | Provider identifier for this model                               |
| api_key                               | Optional[str]                    | None     | API key for authenticating with the provider                     |
| api_base                              | Optional[str]                    | None     | Base URL for the LLM API                                         |
| max_tokens                            | Optional[int]                    | None     | Maximum number of tokens to generate                             |
| temperature                           | float                            | 0.7      | Sampling temperature                                             |
| top_p                                 | float                            | 1.0      | Nucleus sampling probability                                     |
| request_params                        | Optional[Dict[str, Any]]         | None     | Additional parameters sent to the provider                       |
| response_format                       | Optional[Any]                    | None     | Format or schema for structured outputs                          |
| structured_outputs                    | bool                             | False    | Enable structured output mode                                    |
| supports_native_structured_outputs    | bool                             | False    | Whether the model natively supports structured outputs           |
| supports_json_schema_outputs          | bool                             | False    | Whether the model supports JSON schema–based outputs             |
| tools                                 | Optional[List[Dict[str, Any]]]   | None     | List of tool/function definitions provided to the model          |
| functions                             | Optional[Dict[str, Any]]         | None     | Internal function definitions used for execution (not sent)      |
| tool_choice                           | Optional[Union[str, Dict[str,Any]]]| None   | Controls which tool/function to call: "none", "auto", or specific |
| show_tool_calls                       | Optional[bool]                   | None     | Include tool call details in the model response                  |
| tool_call_limit                       | Optional[int]                    | None     | Maximum number of tool calls allowed                             |
| client                                | Any                              | –        | Underlying LLM client instance                                   |
