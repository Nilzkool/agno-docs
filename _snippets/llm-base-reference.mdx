| Parameter                         | Type                             | Default | Description                                                  |
|-----------------------------------|----------------------------------|---------|--------------------------------------------------------------|
| id                                | str                              | -       | ID of the model to use.                                      |
| name                              | Optional[str]                    | None    | Name for this Model. Not sent to the LLM API.               |
| provider                          | Optional[str]                    | None    | Provider name.                                              |
| api_key                           | Optional[str]                    | None    | API key for the model provider.                             |
| api_base                          | Optional[str]                    | None    | Base URL for the API endpoint.                              |
| max_tokens                        | Optional[int]                    | None    | Maximum number of tokens to generate.                        |
| temperature                       | float                            | 0.7     | Sampling temperature.                                        |
| top_p                             | float                            | 1.0     | Nucleus sampling probability.                               |
| request_params                    | Optional[Dict[str, Any]]         | None    | Additional request parameters for completions.              |
| client                            | Optional[Any]                    | None    | Custom client instance (e.g., custom SDK client).           |
| response_format                   | Optional[Any]                    | None    | Format or schema for structured outputs.                    |
| structured_outputs                | bool                             | False   | Whether to use native structured outputs.                   |
| supports_native_structured_outputs| bool                             | False   | Model supports native structured outputs.                   |
| supports_json_schema_outputs      | bool                             | False   | Model supports JSON schema outputs.                         |
| tool_choice                       | Union[str, Dict[str, Any]]       | None    | Controls function calls: “none”, “auto” or specific function. |
| show_tool_calls                   | Optional[bool]                   | None    | Show tool calls in the response.                            |
| tool_call_limit                   | Optional[int]                    | None    | Maximum number of function calls allowed.                   |
| _tools                            | Optional[List[Dict]]             | None    | Tools provided to the model (definitions sent to API).      |
| _functions                        | Optional[Dict[str, Any]]         | None    | Functions extracted from tools (for execution).             |
| system_prompt                     | Optional[str]                    | None    | System prompt added to the model’s input.                   |
| instructions                      | Optional[List[str]]              | None    | Instructions provided to the model.                         |
