| Parameter                              | Type                                       | Default | Description                                                                                                       |
|----------------------------------------|--------------------------------------------|---------|-------------------------------------------------------------------------------------------------------------------|
| id                                     | `str`                                       | -       | ID of the model to use.                                                                                            |
| name                                   | `Optional[str]`                            | -       | Name for this Model. Not sent to the model API.                                                                   |
| provider                               | `Optional[str]`                            | -       | Provider for this Model. Not sent to the model API.                                                              |
| response_format                        | `Optional[Any]`                            | `None`  | Format for structured outputs, e.g. JSON schema or Pydantic model.                                                |
| structured_outputs                     | `bool`                                     | `False` | Whether to generate structured outputs.                                                                           |
| supports_native_structured_outputs     | `bool`                                     | `False` | True if model supports native structured outputs.                                                                 |
| supports_json_schema_outputs           | `bool`                                     | `False` | True if model requires a JSON schema for structured outputs.                                                       |
| tool_choice                            | `Optional[Union[str, Dict[str, Any]]]`     | `None`  | Controls function-call behavior: “none”, “auto”, or specify a particular function to call.                      |
| show_tool_calls                        | `Optional[bool]`                           | `None`  | If True, include tool calls in the responses.                                                                     |
| tool_call_limit                        | `Optional[int]`                            | `None`  | Maximum number of function/tool calls allowed.                                                                    |
| tools                                  | `Optional[List[Dict]]`                     | `None`  | List of tools provided to the model (sent to the API for function calls).                                         |
| functions                              | `Optional[Dict[str, Function]]`            | `None`  | Functions extracted from tools for local execution. Not sent to the model API.                                     |
| system_prompt                          | `Optional[str]`                            | `None`  | System prompt added at the start of conversation messages.                                                         |
| instructions                           | `Optional[List[str]]`                      | `None`  | Instructions appended to the system message or user prompt.                                                       |
