| Parameter                         | Type                        | Default    | Description                                                                                     |
|-----------------------------------|-----------------------------|------------|-------------------------------------------------------------------------------------------------|
| `id`                              | `str`                       | -          | ID of the model to use.                                                                         |
| `name`                            | `Optional[str]`             | `None`     | Name for this Model (not sent to the API).                                                      |
| `provider`                        | `Optional[str]`             | `None`     | Provider for this Model.                                                                        |
| `response_format`                 | `Any`                       | `None`     | Format of the response (e.g., JSON object or JSON schema).                                      |
| `structured_outputs`              | `bool`                      | `False`    | Whether to generate structured outputs.                                                         |
| `supports_native_structured_outputs` | `bool`                  | `False`    | True if the model supports structured outputs natively.                                         |
| `supports_json_schema_outputs`    | `bool`                      | `False`    | True if the model supports JSON schema outputs.                                                 |
| `tool_choice`                     | `Union[str, Dict[str, Any]]`| `None`     | Controls tool/function call behavior (`"none"`, `"auto"`, or specify a function).          |
| `show_tool_calls`                 | `Optional[bool]`            | `None`     | Whether to include tool calls in the model’s response.                                         |
| `tool_call_limit`                 | `Optional[int]`             | `None`     | Maximum number of tool/function calls allowed.                                                  |
| `system_prompt`                   | `Optional[str]`             | `None`     | Custom system prompt to prepend to the conversation.                                            |
| `instructions`                    | `Optional[List[str]]`       | `None`     | List of instructions to include in the prompt for the model.                                    |
