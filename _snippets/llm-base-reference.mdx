---
description: Base parameters for LLM models in Agno
---

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `id` | `str` | — | ID of the model to use |
| `name` | `Optional[str]` | `None` | Name for this model (not sent to the API) |
| `provider` | `Optional[str]` | `None` | Provider name for this model |
| `response_format` | `Any` | `None` | Format of the response |
| `structured_outputs` | `bool` | `False` | Whether to enable structured outputs |
| `supports_native_structured_outputs` | `bool` | `False` | Model natively supports structured outputs |
| `supports_json_schema_outputs` | `bool` | `False` | Model supports JSON schema outputs |
| `tools` | `Optional[List[Dict]]` | `None` | Tools provided to the model (functions to call) |
| `functions` | `Optional[Dict[str, Function]]` | `None` | Registered functions for tool calls |
| `tool_choice` | `Optional[Union[str, Dict[str,Any]]]` | `None` | How the model selects tools: `none`, `auto`, or a specific function |
| `show_tool_calls` | `Optional[bool]` | `None` | Whether to display tool calls in responses |
| `tool_call_limit` | `Optional[int]` | `None` | Maximum number of tool calls allowed |
| `metrics` | `Optional[Dict[str,Any]]` | `None` | Collected metrics for responses (not sent to API) |
