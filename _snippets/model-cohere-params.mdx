| Parameter            | Type                         | Default             | Description                                                                                                     |
| -------------------- | ---------------------------- | ------------------- | --------------------------------------------------------------------------------------------------------------- |
| `id`                 | `str`                        | `"command-r-plus"`| The specific model ID used for generating responses.                                                             |
| `name`               | `str`                        | `"cohere"`        | The name identifier for this model.                                                                             |
| `provider`           | `str`                        | `"Cohere"`        | The provider of the model.                                                                                     |
| `temperature`        | `Optional[float]`            | `None`              | Sampling temperature between 0 and 2. Higher values produce more random output.                                 |
| `max_tokens`         | `Optional[int]`              | `None`              | Maximum number of tokens to generate in the response.                                                           |
| `top_k`              | `Optional[int]`              | `None`              | Number of highest-probability tokens to keep for top-k filtering.                                              |
| `top_p`              | `Optional[float]`            | `None`              | Nucleus sampling parameter; model considers tokens with cumulative probability ≤ top_p.                         |
| `seed`               | `Optional[int]`              | `None`              | Random seed for deterministic sampling.                                                                         |
| `frequency_penalty`  | `Optional[float]`            | `None`              | Penalizes new tokens based on frequency in text so far, reducing repetition.                                    |
| `presence_penalty`   | `Optional[float]`            | `None`              | Penalizes new tokens based on presence in text so far, encouraging new topics.                                  |
| `logprobs`           | `Optional[bool]`             | `None`              | Whether to return log probabilities for generated tokens.                                                      |
| `strict_tools`       | `bool`                       | `False`             | Enforces that tool parameters strictly match function definitions.                                             |
| `request_params`     | `Optional[Dict[str, Any]]`   | `None`              | Additional parameters to include in the API request.                                                            |
| `add_chat_history`   | `bool`                       | `False`             | Whether to include full chat history in messages instead of using conversation_id.                            |
| `api_key`            | `Optional[str]`              | `None`              | Cohere API key (uses `CO_API_KEY` environment variable if unset).                                               |
| `client_params`      | `Optional[Dict[str, Any]]`   | `None`              | Parameters passed when instantiating the Cohere client.                                                         |
| `client`             | `Optional[CohereClient]`     | `None`              | A pre-configured synchronous Cohere client instance.                                                           |
| `async_client`       | `Optional[CohereAsyncClient]`| `None`              | A pre-configured asynchronous Cohere client instance.                                                          |
