| Parameter            | Type                         | Default                | Description                                                   |
| -------------------- | ---------------------------- | ---------------------- | ------------------------------------------------------------- |
| `id`                 | `str`                        | `"command-r-plus"`   | The specific model ID used for generating responses.          |
| `name`               | `str`                        | `"cohere"`           | The name identifier for the model instance.                   |
| `provider`           | `str`                        | `"Cohere"`           | The provider name.                                            |
| `temperature`        | `Optional[float]`            | `None`                 | Sampling temperature, controls randomness in generation.      |
| `max_tokens`         | `Optional[int]`              | `None`                 | Maximum number of tokens to generate in the response.         |
| `top_k`              | `Optional[int]`              | `None`                 | Keep only the top-k most probable tokens.                     |
| `top_p`              | `Optional[float]`            | `None`                 | Nucleus sampling parameter (cumulative probability).         |
| `seed`               | `Optional[int]`              | `None`                 | Random seed for reproducible sampling.                        |
| `frequency_penalty`  | `Optional[float]`            | `None`                 | Penalize new tokens based on their existing frequency.        |
| `presence_penalty`   | `Optional[float]`            | `None`                 | Penalize new tokens based on whether they appear already.     |
| `logprobs`           | `Optional[bool]`             | `None`                 | Return log probabilities for generated tokens.                |
| `request_params`     | `Optional[Dict[str, Any]]`   | `None`                 | Additional API request parameters.                           |
| `strict_tools`       | `bool`                       | `False`                | Enforce strict validation of tool parameters.                |
| `add_chat_history`   | `bool`                       | `False`                | Include full chat history instead of conversation ID.        |
| `api_key`            | `Optional[str]`              | `None`                 | Cohere API key for authentication.                           |
| `client_params`      | `Optional[Dict[str, Any]]`   | `None`                 | Additional client configuration parameters.                  |
| `client`             | `Optional[CohereClient]`     | `None`                 | Pre-configured synchronous Cohere client instance.           |
| `async_client`       | `Optional[CohereAsyncClient]`| `None`                 | Pre-configured asynchronous Cohere client instance.          |
