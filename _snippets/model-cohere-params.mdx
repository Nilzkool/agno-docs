| Parameter           | Type                         | Default             | Description                                                                              |
|---------------------|------------------------------|---------------------|------------------------------------------------------------------------------------------|
| `id`                | `str`                        | `"command-r-plus"` | The specific model ID used for generating responses.                                     |
| `name`              | `str`                        | `"cohere"`         | The name identifier for the model instance.                                              |
| `provider`          | `str`                        | `"Cohere"`         | The provider of the model.                                                               |
| `temperature`       | `Optional[float]`            | `None`              | The sampling temperature, between 0 and 2. Higher values yield more random output.        |
| `max_tokens`        | `Optional[int]`              | `None`              | The maximum number of tokens to generate in the response.                                |
| `top_k`             | `Optional[int]`              | `None`              | The number of highest-probability tokens to keep for top-k filtering.                    |
| `top_p`             | `Optional[float]`            | `None`              | Nucleus sampling parameter; the model considers tokens with top_p cumulative probability.|
| `seed`              | `Optional[int]`              | `None`              | The random seed for deterministic sampling.                                              |
| `frequency_penalty` | `Optional[float]`            | `None`              | Penalizes new tokens based on their frequency in the text so far.                        |
| `presence_penalty`  | `Optional[float]`            | `None`              | Penalizes new tokens based on whether they appear in the text so far.                    |
| `logprobs`          | `Optional[bool]`             | `None`              | Include log probabilities on the most likely tokens.                                     |
| `request_params`    | `Optional[Dict[str, Any]]`   | `None`              | Additional parameters to include in the API request.                                     |
| `strict_tools`      | `bool`                       | `False`             | Whether to enforce strict validation of tool parameter schemas.                          |
| `add_chat_history`  | `bool`                       | `False`             | Add chat history to the Cohere request instead of using a conversation ID.               |
| `api_key`           | `Optional[str]`              | `None`              | The API key for authenticating requests to Cohere.                                       |
| `client_params`     | `Optional[Dict[str, Any]]`   | `None`              | Additional parameters for configuring the Cohere client.                                 |
| `client`            | `Optional[CohereClient]`     | `None`              | A pre-configured synchronous Cohere client instance.                                     |
| `async_client`      | `Optional[CohereAsyncClient]`| `None`              | A pre-configured asynchronous Cohere client instance.                                    |
