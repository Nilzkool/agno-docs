| Parameter         | Type                         | Default               | Description                                              |
| ----------------- | ---------------------------- | --------------------- | -------------------------------------------------------- |
| `id`              | `str`                        | `"command-r-plus"`  | The specific Cohere model ID used for generating responses. |
| `name`            | `str`                        | `"cohere"`          | The name identifier for the model instance.              |
| `provider`        | `str`                        | `"Cohere"`          | The provider of the model.                               |
| `temperature`     | `Optional[float]`            | `None`                | Sampling temperature; higher values yield more randomness. |
| `max_tokens`      | `Optional[int]`              | `None`                | Maximum number of tokens to generate in the response.    |
| `top_k`           | `Optional[int]`              | `None`                | Keep only the top-k highest probability tokens.          |
| `top_p`           | `Optional[float]`            | `None`                | Nucleus sampling parameter; cumulative probability mass. |
| `seed`            | `Optional[int]`              | `None`                | Random seed for reproducible sampling.                   |
| `frequency_penalty` | `Optional[float]`          | `None`                | Penalizes tokens by their existing frequency.            |
| `presence_penalty`  | `Optional[float]`          | `None`                | Penalizes tokens by their presence to encourage new topics. |
| `logprobs`        | `Optional[bool]`             | `None`                | Include log probabilities of generated tokens.           |
| `request_params`  | `Optional[Dict[str, Any]]`   | `None`                | Additional parameters to include in the API request.     |
| `strict_tools`    | `bool`                       | `False`               | Whether to enforce strict schema when calling tools.     |
| `add_chat_history`| `bool`                       | `False`               | Add full chat history to messages instead of conversation_id. |
| `api_key`         | `Optional[str]`              | `None`                | API key for authenticating with the Cohere service.      |
| `client_params`   | `Optional[Dict[str, Any]]`   | `None`                | Extra parameters for client configuration.               |
| `client`          | `Optional[CohereClient]`     | `None`                | A pre-configured synchronous Cohere client.              |
| `async_client`    | `Optional[CohereAsyncClient]`| `None`                | A pre-configured asynchronous Cohere client.             |
