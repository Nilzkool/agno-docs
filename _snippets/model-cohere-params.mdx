| Parameter                | Type                         | Default                    | Description                                                                                                                                                                                     |
| ------------------------ | ---------------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`                     | `str`                        | "command-r-plus"         | The specific model ID used for generating responses.                                                                                                                                          |
| `name`                   | `str`                        | "cohere"                 | The name identifier for the model.                                                                                                                                                              |
| `provider`               | `str`                        | "Cohere"                 | The model provider.                                                                                                                                                                             |
| `temperature`            | `Optional[float]`            | `None`                     | Controls the output randomness. Higher values produce more random responses while lower values make outputs more deterministic.                                                                |
| `max_tokens`             | `Optional[int]`              | `None`                     | Maximum number of tokens to generate in the response.                                                                                                                                         |
| `top_k`                  | `Optional[int]`              | `None`                     | The number of highest probability tokens to consider for top-k filtering.                                                                                                                     |
| `top_p`                  | `Optional[float]`            | `None`                     | Nucleus sampling parameter that defines the cumulative probability threshold for token selection.                                                                                             |
| `seed`                   | `Optional[int]`              | `None`                     | Random seed for deterministic sampling.                                                                                                                                                       |
| `frequency_penalty`      | `Optional[float]`            | `None`                     | Penalizes tokens based on their frequency in the generated text, reducing repetition.                                                                                                          |
| `presence_penalty`       | `Optional[float]`            | `None`                     | Penalizes tokens that have already appeared to encourage new topics.                                                                                                                          |
| `logprobs`               | `Optional[bool]`             | `None`                     | Whether to include log probabilities for the generated tokens.                                                                                                                                |
| `request_params`         | `Optional[Dict[str, Any]]`   | `None`                     | Additional parameters to include in the API request.                                                                                                                                          |
| `strict_tools`           | `bool`                       | `False`                    | Enables strict validation for tool usage in the model.                                                                                                                                        |
| `add_chat_history`       | `bool`                       | `False`                    | If true, the model will include prior conversation history instead of using a conversation ID.                                                                                                |
| `api_key`                | `Optional[str]`              | `None`                     | API key for authenticating requests to Cohere.                                                                                                                                                  |
| `client_params`          | `Optional[Dict[str, Any]]`   | `None`                     | Additional parameters for configuring the Cohere client.                                                                                                                                      |
| `client`                 | `Optional[CohereClient]`     | `None`                     | A pre-configured instance of the Cohere client.                                                                                                                                                |
| `async_client`           | `Optional[CohereAsyncClient]`| `None`                     | A pre-configured instance of the asynchronous Cohere client.                                                                                                                                  |
