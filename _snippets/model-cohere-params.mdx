| Parameter          | Type                       | Default              | Description                                                                                           |
| ------------------ | -------------------------- | -------------------- | ----------------------------------------------------------------------------------------------------- |
| `id`               | `str`                      | `"command-r-plus"` | The specific Cohere model ID used for generation.                                                     |
| `name`             | `str`                      | `"cohere"`         | The local name identifier for this model instance.                                                    |
| `provider`         | `str`                      | `"Cohere"`         | The provider name for this model.                                                                     |
| `temperature`      | `Optional[float]`          | `None`               | Sampling temperature (0–2). Controls randomness in generation.                                         |
| `max_tokens`       | `Optional[int]`            | `None`               | Maximum number of tokens to generate in the response.                                                 |
| `top_k`            | `Optional[int]`            | `None`               | Top-k filtering parameter. Limits to highest-probability tokens.                                      |
| `top_p`            | `Optional[float]`          | `None`               | Nucleus sampling parameter. Considers tokens up to this cumulative probability.                       |
| `seed`             | `Optional[int]`            | `None`               | Random seed for reproducible sampling.                                                                |
| `logprobs`         | `Optional[bool]`           | `None`               | Whether to include log-probabilities of generated tokens.                                             |
| `frequency_penalty`| `Optional[float]`          | `None`               | Penalizes new tokens based on frequency in the generated text.                                        |
| `presence_penalty` | `Optional[float]`          | `None`               | Penalizes new tokens based on whether they appear in the text so far.                                 |
| `request_params`   | `Optional[Dict[str,Any]]`  | `None`               | Extra parameters passed directly to the API request.                                                  |
| `strict_tools`     | `bool`                     | `False`              | Enforce strict parameter validation when invoking tools.                                              |
| `add_chat_history` | `bool`                     | `False`              | Include chat history with each request instead of using a conversation ID.                            |
| `api_key`          | `Optional[str]`            | `None`               | API key for authenticating with Cohere.                                                               |
| `client_params`    | `Optional[Dict[str,Any]]`  | `None`               | Additional keyword args for the Cohere client constructor.                                            |
| `client`           | `Optional[CohereClient]`   | `None`               | Pre-configured synchronous Cohere client instance.                                                    |
| `async_client`     | `Optional[CohereAsyncClient]` | `None`            | Pre-configured asynchronous Cohere client instance.                                                   |
