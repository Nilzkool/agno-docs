| Parameter               | Type                         | Default               | Description                                                                                                     |
|-------------------------|------------------------------|-----------------------|-----------------------------------------------------------------------------------------------------------------|
| `id`                    | `str`                        | `"command-r-plus"`  | The specific Cohere model ID to use.                                                                            |
| `name`                  | `str`                        | `"cohere"`          | The name identifier for the Cohere model class.                                                                 |
| `provider`              | `str`                        | `"Cohere"`          | The provider name.                                                                                              |
| `temperature`           | `Optional[float]`            | `None`                | Sampling temperature for output randomness (0–2).                                                               |
| `max_tokens`            | `Optional[int]`              | `None`                | Maximum number of tokens to generate.                                                                            |
| `top_k`                 | `Optional[int]`              | `None`                | Top-k sampling limit.                                                                                           |
| `top_p`                 | `Optional[float]`            | `None`                | Nucleus sampling parameter for cumulative probability.                                                          |
| `seed`                  | `Optional[int]`              | `None`                | Seed for deterministic sampling.                                                                                |
| `frequency_penalty`     | `Optional[float]`            | `None`                | Penalty for token frequency.                                                                                    |
| `presence_penalty`      | `Optional[float]`            | `None`                | Penalty for token presence.                                                                                     |
| `logprobs`              | `Optional[bool]`             | `None`                | Whether to return log probabilities for output tokens.                                                          |
| `request_params`        | `Optional[Dict[str, Any]]`   | `None`                | Additional parameters passed directly to the API.                                                               |
| `strict_tools`          | `bool`                       | `False`               | Enforce that declared tools have required parameters.                                                           |
| `add_chat_history`      | `bool`                       | `False`               | Add previous chat messages instead of relying on conversation_id.                                               |
| `api_key`               | `Optional[str]`              | `None`                | Cohere API key (or set via `CO_API_KEY` environment variable).                                                  |
| `client_params`         | `Optional[Dict[str, Any]]`   | `None`                | Extra configuration for the Cohere client.                                                                      |
| `client`                | `Optional[CohereClient]`     | `None`                | Pre-configured Cohere synchronous client instance.                                                              |
| `async_client`          | `Optional[CohereAsyncClient]`| `None`                | Pre-configured Cohere asynchronous client instance.                                                             |
