| Parameter  | Type            | Default                     | Description                                                                                                           |
| ---------- | --------------- | --------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `id`       | `str`           | `"grok-beta"`             | The specific xAI model ID used for generating responses.                                                             |
| `name`     | `str`           | `"xAI"`                   | The name identifier for the xAI API client.                                                                          |
| `provider` | `str`           | `"xAI"`                   | The provider of the model (xAI).                                                                                     |
| `api_key`  | `Optional[str]` | `None`                      | The API key for authenticating requests to the xAI service (from `XAI_API_KEY`).                                    |
| `base_url` | `str`           | `"https://api.x.ai/v1"`   | The base URL for making API requests to the xAI service.                                                            |
