| Parameter  | Type                | Default                    | Description                                                                                           |
| ---------- | ------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------- |
| `id`       | `str`               | `"grok-beta"`            | The default xAI model ID.                                                                            |
| `name`     | `str`               | `"xAI"`                  | The name identifier for the xAI model client.                                                        |
| `provider` | `str`               | `"xAI"`                  | The provider identifier for the xAI API.                                                             |
| `api_key`  | `Optional[str]`     | `None`                     | API key for xAI, from the `XAI_API_KEY` environment variable.                                         |
| `base_url` | `Optional[str]`     | `"https://api.x.ai/v1"`  | The base URL for xAI API requests (default `https://api.x.ai/v1`).                                    |
