| Parameter           | Type                   | Default   | Description                                                |
|---------------------|------------------------|-----------|------------------------------------------------------------|
| `session_id`        | `str`                  | Required  | Session UUID                                               |
| `team_session_id`   | `Optional[str]`       | `None`    | ID of the parent team session (for sub-teams)              |
| `team_id`           | `Optional[str]`       | `None`    | ID of the team that this session is associated with       |
| `user_id`           | `Optional[str]`       | `None`    | ID of the user interacting with this team                 |
| `memory`            | `Optional[Dict[str, Any]]` | `None`    | Stored team memory                                         |
| `team_data`         | `Optional[Dict[str, Any]]` | `None`    | Metadata: team_id, name, model                             |
| `session_data`      | `Optional[Dict[str, Any]]` | `None`    | Data: session_name, session_state, images, videos, audio  |
| `extra_data`        | `Optional[Dict[str, Any]]` | `None`    | Extra data stored with this session                        |
| `created_at`        | `Optional[int]`       | `None`    | Unix timestamp when session was created                   |
| `updated_at`        | `Optional[int]`       | `None`    | Unix timestamp when session was last updated              |
