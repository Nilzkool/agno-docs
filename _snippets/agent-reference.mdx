## Parameters

| Parameter                         | Type                                              | Default   | Description                                                                                                                                             |
|-----------------------------------|---------------------------------------------------|-----------|---------------------------------------------------------------------------------------------------------------------------------------------------------|
| `model`                           | `Optional[Model]`                                 | `None`    | Model to use for this Agent                                                                                                                             |
| `name`                            | `Optional[str]`                                   | `None`    | Agent name                                                                                                                                              |
| `agent_id`                        | `Optional[str]`                                   | `None`    | Agent UUID (autogenerated if not set)                                                                                                                   |
| `introduction`                    | `Optional[str]`                                   | `None`    | Agent introduction added to history when a run starts                                                                                                   |
| `user_id`                         | `Optional[str]`                                   | `None`    | Default user ID to use for this agent                                                                                                                   |
| `session_id`                      | `Optional[str]`                                   | `None`    | Default session ID (autogenerated if not set)                                                                                                           |
| `session_name`                    | `Optional[str]`                                   | `None`    | Session name                                                                                                                                             |
| `session_state`                   | `Optional[Dict[str, Any]]`                        | `None`    | Session state persisted across runs in storage                                                                                                          |
| `context`                         | `Optional[Dict[str, Any]]`                        | `None`    | Arbitrary context for tools and prompt functions                                                                                                        |
| `add_context`                     | `bool`                                            | `False`   | If true, include `context` in the user prompt                                                                                                          |
| `resolve_context`                 | `bool`                                            | `True`    | If true, call any functions in `context` before running                                                                                                 |
| `memory`                          | `Optional[Union[AgentMemory, Memory]]`            | `None`    | Agent memory backend                                                                                                                                     |
| `enable_agentic_memory`           | `bool`                                            | `False`   | If true, agent maintains its own memory of user interactions                                                                                            |
| `enable_user_memories`            | `bool`                                            | `False`   | If true, agent updates user memories at end of runs                                                                                                     |
| `add_memory_references`           | `Optional[bool]`                                  | `None`    | If true, include references to user memories in responses                                                                                               |
| `enable_session_summaries`        | `bool`                                            | `False`   | If true, agent creates session summaries at end of runs                                                                                                 |
| `add_session_summary_references`  | `Optional[bool]`                                  | `None`    | If true, include session summaries references in responses                                                                                             |
| `add_history_to_messages`         | `bool`                                            | `False`   | If true, prepend recent chat history to messages sent to model                                                                                          |
| `num_history_responses`           | `Optional[int]`                                   | `None`    | (Deprecated) number of past responses to include                                                                                                        |
| `num_history_runs`                | `int`                                             | `3`       | Number of recent runs whose history is included                                                                                                        |
| `knowledge`                       | `Optional[AgentKnowledge]`                        | `None`    | Agent knowledge base for RAG                                                                                                                            |
| `add_references`                  | `bool`                                            | `False`   | If true, include retrieved knowledge references in prompts                                                                                              |
| `retriever`                       | `Optional[Callable[..., Any]]`                    | `None`    | Custom function to retrieve knowledge                                                                                                                   |
| `references_format`               | `Literal["json","yaml"]`                      | `
