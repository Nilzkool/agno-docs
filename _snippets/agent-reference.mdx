## Parameters

| Parameter                         | Type                                | Default    | Description                                                                                                             |
|-----------------------------------|-------------------------------------|------------|-------------------------------------------------------------------------------------------------------------------------|
| `model`                           | `Optional[Model]`                   | `None`     | Model to use for this Agent                                                                                             |
| `name`                            | `Optional[str]`                     | `None`     | Agent name                                                                                                              |
| `agent_id`                        | `Optional[str]`                     | `None`     | Agent UUID (autogenerated if not set)                                                                                   |
| `introduction`                    | `Optional[str]`                     | `None`     | Agent introduction. This is added to the message history when a run is started.                                          |
| `user_id`                         | `Optional[str]`                     | `None`     | ID of the user interacting with this Agent                                                                              |
| `session_id`                      | `Optional[str]`                     | `None`     | Session UUID (autogenerated if not set)                                                                                 |
| `session_name`                    | `Optional[str]`                     | `None`     | Session name                                                                                                            |
| `session_state`                   | `Optional[Dict[str, Any]]`          | `None`     | Session state (persisted across runs)                                                                                    |
| `context`                         | `Optional[Dict[str, Any]]`          | `None`     | Context available for tools and prompt functions                                                                        |
| `add_context`                     | `bool`                              | `False`    | If True, add the context to the user prompt                                                                             |
| `resolve_context`                 | `bool`                              | `True`     | If True, resolve callables in context before running the Agent                                                          |
| `memory`                          | `Optional[Union[AgentMemory, Memory]]`| `None`   | Agent memory backend                                                                                                    |
| `enable_agentic_memory`           | `bool`                              | `False`    | Allow Agent to manage user memories internally                                                                          |
| `enable_user_memories`            | `bool`                              | `False`    | Agent will create/update user memories at end of runs                                                                   |
| `add_memory_references`           | `bool`                              | `None`     | Add references to memories in responses                                                                                 |
| `enable_session_summaries`        | `bool`                              | `False`    | Agent will create/update session summaries at end of runs                                                               |
| `add_session_summary_references`  | `bool`                              | `None`     | Add references to session summaries in responses                                                                        |
| `add_history_to_messages`         | `bool`                              | `False`    | Include chat history in messages sent to the model                                                                      |
| `num_history_responses`           | `Optional[int]`                     | `None`     | Number of historical responses (deprecated in favor of `num_history_runs`)                                              |
| `num_history_runs`                | `int`                               | `3`        | Number of historical runs to include in messages                                                                        |
| `knowledge`                       | `Optional[AgentKnowledge]`          | `None`     | Agent knowledge base for RAG                                                                                            |
| `add_references`                  | `bool`                              | `False`    | Include retrieval references in user prompt                                                                             |
| `retriever`                       | `Optional[Callable[..., Any]]`      | `None`     | Custom function to retrieve documents for RAG                                                                           |
| `references_format`               | `Literal["json","yaml"]`        | `json`     | Format for RAG references                                                                                               |
| `storage`                         | `Optional[Storage]`                 | `None`     | Persistent storage backend                                                                                              |
| `extra_data`                      | `Optional[Dict[str, Any]]`          | `None`     | Additional metadata stored with this Agent                                                                               |
| `tools`                           | `Optional[List[Union[Toolkit, Callable, Function, Dict]]]` | `None` | Custom tools available to the model                                                                                     |
| `show_tool_calls`                 | `bool`                              | `True`     | Display tool calls in the Agent response                                                                                |
| `tool_call_limit`                 | `Optional[int]`                     | `None`     | Maximum number of tool calls per run                                                                                    |
| `tool_choice`                     | `Optional[Union[str, Dict[str,Any]]]` | `None`   | Strategy or specific tool for forcing function calls                                                                   |
| `reasoning`                       | `bool`                              | `False`    | Enable step-by-step chain-of-thought reasoning                                                                           |
| `reasoning_model`                 | `Optional[Model]`                   | `None`     | Model to use for internal reasoning steps                                                                               |
| `reasoning_agent`                 | `Optional[Agent]`                   | `None`     | Agent wrapper for the reasoning model                                                                                   |
| `reasoning_min_steps`             | `int`                               | `1`        | Minimum reasoning steps                                                                                                  |
| `reasoning_max_steps`             | `int`                               | `10`       | Maximum reasoning steps                                                                                                  |
| `read_chat_history`               | `bool`                              | `False`    | Provide a function to read chat history                                                                                  |
| `search_knowledge`                | `bool`                              | `True`     | Provide a function to query knowledge base                                                                              |
| `update_knowledge`                | `bool`                              | `False`    | Provide a function to add documents to the knowledge base                                                               |
| `read_tool_call_history`          | `bool`                              | `False`    | Provide a function to query past tool calls                                                                             |
| `system_message`                  | `Optional[Union[str,Callable,Message]]` | `None` | Custom system message or generator                                                                                      |
| `system_message_role`             | `str`                               | `system`   | Role assigned to the system message                                                                                     |
| `create_default_system_message`   | `bool`                              | `True`     | Generate a built-in system prompt from Agent settings                                                                   |
| `description`                     | `Optional[str]`                     | `None`     | High-level Agent description included in system prompt                                                                  |
| `goal`                            | `Optional[str]`                     | `None`     | Task goal instructions wrapped in `<your_goal>` tags                                                                    |
| `instructions`                    | `Optional[Union[str,List[str],Callable]]` | `None` | Instructions list for the Agent                                                                                         |
| `expected_output`                 | `Optional[str]`                     | `None`     | Template of expected output wrapped in `<expected_output>` tags                                                          |
| `additional_context`              | `Optional[str]`                     | `None`     | Extra context appended to system prompt                                                                                  |
| `markdown`                        | `bool`                              | `False`    | If True, include markdown formatting instructions                                                                       |
| `add_name_to_instructions`        | `bool`                              | `False`    | Insert Agent name into instruction section                                                                              |
| `add_datetime_to_instructions`    | `bool`                              | `False`    | Add current datetime to instructions                                                                                    |
| `add_state_in_messages`           | `bool`                              | `False`    | Inject session state into outgoing messages                                                                             |
| `add_messages`                    | `Optional[List[Union[Dict,Message]]]` | `None`   | Additional messages to add after system message                                                                         |
| `user_message`                    | `Optional[Union[str,List,Dict,Callable,Message]]` | `None` | Custom user message or generator                                                                                        |
| `user_message_role`               | `str`                               | `user`     | Role assigned to user message                                                                                            |
| `create_default_user_message`     | `bool`                              | `True`     | Build a default user message from incoming message and references                                                       |
| `retries`                         | `int`                               | `0`        | Number of retry attempts on failure                                                                                     |
| `delay_between_retries`           | `int`                               | `1`        | Delay in seconds between retry attempts                                                                                 |
| `exponential_backoff`             | `bool`                              | `False`    | If True, double the retry delay after each failure                                                                       |
| `response_model`                  | `Optional[Type[BaseModel]]`         | `None`     | Pydantic model for validating structured outputs                                                                         |
| `parse_response`                  | `bool`                              | `True`     | Convert string responses into `response_model` instances                                                                 |
| `structured_outputs`              | `Optional[bool]`                    | `None`     | Override native structured output support                                                                                |
| `use_json_mode`                   | `bool`                              | `False`    | Force JSON schema output instead of native Pydantic                                                                     |
| `save_response_to_file`           | `Optional[str]`                     | `None`     | Format string path to save Agent responses to files                                                                     |
| `stream`                          | `Optional[bool]`                    | `None`     | Stream complete responses                                                                                                |
| `stream_intermediate_steps`       | `bool`                              | `False`    | Stream partial and reasoning events                                                                                     |
| `debug_mode`                      | `bool`                              | `False`    | Enable detailed debug logs                                                                                              |
| `monitoring`                      | `bool`                              | `False`    | Send telemetry for monitoring                                                                                            |
| `telemetry`                       | `bool`                              | `True`     | Enable minimal telemetry for analytics                                                                                  |
