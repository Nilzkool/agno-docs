## Parameters

| Parameter                          | Type                                           | Default                                         | Description |
|------------------------------------|------------------------------------------------|-------------------------------------------------|-------------|
| `model`                            | `Optional[Model]`                              | `None`                                          | Model to use for this Agent |
| `name`                             | `Optional[str]`                                | `None`                                          | Agent name |
| `agent_id`                         | `Optional[str]`                                | `None`                                          | Agent UUID (autogenerated if not set) |
| `introduction`                     | `Optional[str]`                                | `None`                                          | Agent introduction added to history on run start |
| `user_id`                          | `Optional[str]`                                | `None`                                          | Default user ID for this agent |
| `session_id`                       | `Optional[str]`                                | `None`                                          | Session UUID (autogenerated if not set) |
| `session_name`                     | `Optional[str]`                                | `None`                                          | Session name |
| `session_state`                    | `Optional[Dict[str, Any]]`                     | `None`                                          | Session state persisted across runs |
| `context`                          | `Optional[Dict[str, Any]]`                     | `None`                                          | Context available for tools and prompts |
| `add_context`                      | `bool`                                         | `False`                                         | If True, include context in user prompt |
| `resolve_context`                  | `bool`                                         | `True`                                          | If True, call any functions in context before run |
| `memory`                           | `Optional[Union[AgentMemory, Memory]]`         | `None`                                          | Agent memory backend |
| `enable_agentic_memory`            | `bool`                                         | `False`                                         | Allow agent to create/​update its own memories |
| `enable_user_memories`             | `bool`                                         | `False`                                         | Enable creation of user memories at run end |
| `add_memory_references`            | `Optional[bool]`                               | `None`                                          | Add memory reference to agent response |
| `enable_session_summaries`        | `bool`                                         | `False`                                         | Create session summaries at run end |
| `add_session_summary_references`  | `Optional[bool]`                               | `None`                                          | Add summary reference to agent response |
| `add_history_to_messages`         | `bool`                                         | `False`                                         | Prepend chat history to messages sent to model |
| `num_history_responses`           | `Optional[int]`                                | `None`                                          | Deprecated: responses to include; use `num_history_runs` |
| `num_history_runs`                | `int`                                          | `3`                                             | Number of historical runs to include |
| `knowledge`                       | `Optional[AgentKnowledge]`                     | `None`                                          | Agent knowledge base |
| `add_references`                  | `bool`                                         | `False`                                         | Enable RAG references in user prompt |
| `retriever`                       | `Optional[Callable[..., Optional[List[Dict]]]]` | `None`                                          | Custom function to retrieve references |
| `references_format`               | `Literal["json","yaml"]`                   | `
