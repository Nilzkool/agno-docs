## Parameters

| Parameter                          | Type                                           | Default       | Description                                                                                 |
|------------------------------------|------------------------------------------------|---------------|---------------------------------------------------------------------------------------------|
| `model`                            | `Optional[Model]`                              | `None`        | Model to use for this Agent                                                                 |
| `name`                             | `Optional[str]`                                | `None`        | Agent name                                                                                  |
| `agent_id`                         | `Optional[str]`                                | `None`        | Agent UUID (autogenerated if not set)                                                       |
| `introduction`                     | `Optional[str]`                                | `None`        | Introduction added to chat history at run start                                             |
| `user_id`                          | `Optional[str]`                                | `None`        | Default user ID                                                                              |
| `session_id`                       | `Optional[str]`                                | `None`        | Default session UUID (autogenerated if not set)                                             |
| `session_name`                     | `Optional[str]`                                | `None`        | Session name                                                                                |
| `session_state`                    | `Optional[Dict[str, Any]]`                     | `None`        | Session state persisted across runs                                                         |
| `context`                          | `Optional[Dict[str, Any]]`                     | `None`        | Context available for tools and prompt functions                                            |
| `add_context`                      | `bool`                                         | `False`       | If True, append `context` to user prompt                                                    |
| `resolve_context`                  | `bool`                                         | `True`        | If True, call any functions in `context` before running                                     |
| `memory`                           | `Optional[Union[AgentMemory, Memory]]`         | `None`        | Agent memory backend                                                                       |
| `enable_agentic_memory`            | `bool`                                         | `False`       | If True, agent manages user memories                                                        |
| `enable_user_memories`             | `bool`                                         | `False`       | If True, agent creates/updates user memories after each run                                  |
| `add_memory_references`            | `Optional[bool]`                               | `None`        | If True, include memory references in responses                                             |
| `enable_session_summaries`         | `bool`                                         | `False`       | If True, agent creates/updates session summaries                                            |
| `add_session_summary_references`   | `Optional[bool]`                               | `None`        | If True, include session summary references in responses                                    |
| `add_history_to_messages`          | `bool`                                         | `False`       | If True, include chat history messages in model call                                        |
| `num_history_responses`            | `Optional[int]`                                | `None`        | Deprecated alias for `num_history_runs`                                                     |
| `num_history_runs`                 | `int`                                          | `3`           | Number of past runs to include in history                                                   |
| `knowledge`                        | `Optional[AgentKnowledge]`                     | `None`        | RAG knowledge base                                                                         |
| `add_references`                   | `bool`                                         | `False`       | If True, enrich prompts with knowledge references                                           |
| `retriever`                        | `Optional[Callable[..., List[Dict]]]`          | `None`        | Custom function to retrieve docs                                                            |
| `references_format`                | `Literal["json","yaml"]`                   | `"json"`    | Format for knowledge references                                                            |
| `storage`                          | `Optional[Storage]`                            | `None`        | Persistent session storage                                                                 |
| `extra_data`                       | `Optional[Dict[str, Any]]`                     | `None`        | Arbitrary metadata stored with the agent                                                     |
| `tools`                            | `Optional[List[Union[Toolkit,Callable,Function,Dict]]]` | `None`        | Tools exposed to the model                                                                  |
| `show_tool_calls`                  | `bool`                                         | `True`        | If True, display tool call details in responses                                             |
| `tool_call_limit`                  | `Optional[int]`                                | `None`        | Maximum number of tool calls allowed                                                        |
| `tool_choice`                      | `Optional[Union[str,Dict]]`                    | `None`        | Controls model’s tool calling behavior                                                      |
| `reasoning`                        | `bool`                                         | `False`       | If True, enable step-by-step reasoning                                                      |
| `reasoning_model`                  | `Optional[Model]`                              | `None`        | Model to drive the reasoning agent                                                          |
| `reasoning_agent`                  | `Optional[Agent]`                              | `None`        | Agent instance used for chain-of-thought reasoning                                           |
| `reasoning_min_steps`              | `int`                                          | `1`           | Minimum reasoning steps                                                                    |
| `reasoning_max_steps`              | `int`                                          | `10`          | Maximum reasoning steps                                                                    |
| `read_chat_history`                | `bool`                                         | `False`       | If True, add a tool to fetch chat history                                                   |
| `search_knowledge`                 | `bool`                                         | `True`        | If True, add a tool for knowledge search                                                    |
| `update_knowledge`                 | `bool`                                         | `False`       | If True, add a tool to update the knowledge base                                             |
| `read_tool_call_history`           | `bool`                                         | `False`       | If True, add a tool to inspect past tool calls                                               |
| `system_message`                   | `Optional[Union[str,Callable,Message]]`        | `None`        | Custom system prompt or builder                                                             |
| `system_message_role`              | `str`                                          | `"system"`  | Role tag for system messages                                                                |
| `create_default_system_message`    | `bool`                                         | `True`        | If False, skip default system prompt generation                                              |
| `description`                      | `Optional[str]`                                | `None`        | Short summary prepended to system prompt                                                     |
| `goal`                             | `Optional[str]`                                | `None`        | High-level goal embedded in default prompt                                                  |
| `instructions`                     | `Optional[Union[str,List[str],Callable]]`      | `None`        | List of guidance directives for the model                                                   |
| `expected_output`                  | `Optional[str]`                                | `None`        | If set, appended as `<expected_output>` section                                              |
| `additional_context`               | `Optional[str]`                                | `None`        | Extra note appended to end of system prompt                                                  |
| `markdown`                         | `bool`                                         | `False`       | If True, advise model to format replies in Markdown                                          |
| `add_name_to_instructions`         | `bool`                                         | `False`       | If True, include agent name in instructions                                                  |
| `add_datetime_to_instructions`     | `bool`                                         | `False`       | If True, include current datetime in instructions                                            |
| `timezone_identifier`              | `Optional[str]`                                | `None`        | TZ identifier for formatting datetime                                                        |
| `add_state_in_messages`            | `bool`                                         | `False`       | If True, interpolate `session_state` into prompts                                            |
| `add_messages`                     | `Optional[List[Union[Dict,Message]]]`          | `None`        | Extra messages to inject after system prompt                                                 |
| `user_message`                     | `Optional[Union[List,Dict,str,Callable,Message]]` | `None`        | Custom user prompt or builder                                                                |
| `user_message_role`                | `str`                                          | `"user"`    | Role tag for user messages                                                                   |
| `create_default_user_message`      | `bool`                                         | `True`        | If False, skip default user prompt                                                           |
| `retries`                          | `int`                                          | `0`           | Number of retry attempts                                                                    |
| `delay_between_retries`            | `int`                                          | `1`           | Delay (seconds) between retries                                                              |
| `exponential_backoff`              | `bool`                                         | `False`       | If True, backoff doubled each retry                                                          |
| `structured_outputs`               | `Optional[bool]`                               | `None`        | If True, prefer model’s native structured outputs                                             |
| `response_model`                   | `Optional[Type[BaseModel]]`                    | `None`        | Pydantic model for validating and parsing output                                             |
| `parse_response`                   | `bool`                                         | `True`        | If True, convert response text to `response_model`                                          |
| `use_json_mode`                    | `bool`                                         | `False`       | If True, enforce JSON schema output instead of native                                        |
| `save_response_to_file`            | `Optional[str]`                                | `None`        | File path format to save run response                                                        |
| `stream`                           | `Optional[bool]`                               | `None`        | If True, stream assistant responses                                                          |
| `stream_intermediate_steps`        | `bool`                                         | `False`       | If True, stream reasoning & tool events                                                      |
| `team`                             | `Optional[List[Agent]]`                        | `None`        | Team of agents available for task transfer                                                   |
| `team_data`                        | `Optional[Dict[str, Any]]`                     | `None`        | Shared metadata with team members                                                            |
| `role`                             | `Optional[str]`                                | `None`        | Role when this agent is part of a team                                                       |
| `respond_directly`                 | `bool`                                         | `False`       | If True, member agent responds directly                                                      |
| `add_transfer_instructions`        | `bool`                                         | `True`        | If True, include task transfer syntax in system prompt                                       |
| `team_response_separator`          | `str`                                          | `"\n"`     | Separator between responses from different team members                                      |
| `debug_mode`                       | `bool`                                         | `False`       | If True, enable verbose debug logging                                                         |
| `monitoring`                       | `bool`                                         | `False`       | If True, send session and run telemetry                                                      |
| `telemetry`                        | `bool`                                         | `True`        | If True, send minimal telemetry information                                                  |
