## Parameters

| Parameter                           | Type                                | Default   | Description                                                                                              |
|-------------------------------------|-------------------------------------|-----------|----------------------------------------------------------------------------------------------------------|
| `model`                             | `Optional[Model]`                   | `None`    | Model to use for this Agent                                                                              |
| `name`                              | `Optional[str]`                     | `None`    | Agent name                                                                                               |
| `agent_id`                          | `Optional[str]`                     | `None`    | Agent UUID (autogenerated if not set)                                                                    |
| `introduction`                      | `Optional[str]`                     | `None`    | Agent introduction. This is added to the chat history when a run is started.                             |
| `user_id`                           | `Optional[str]`                     | `None`    | Default user_id to use for this agent                                                                    |
| `session_id`                        | `Optional[str]`                     | `None`    | Default session_id to use for this agent (autogenerated if not set)                                      |
| `session_name`                      | `Optional[str]`                     | `None`    | Session name                                                                                             |
| `session_state`                     | `Optional[Dict[str, Any]]`          | `None`    | Session state (stored in the database to persist across runs)                                             |
| `context`                           | `Optional[Dict[str, Any]]`          | `None`    | Context available for tools and prompt functions                                                          |
| `add_context`                       | `bool`                              | `False`   | If True, add the context to the user prompt                                                              |
| `resolve_context`                   | `bool`                              | `True`    | If True, resolve the context (i.e. call any functions in the context) before running the agent            |
| `memory`                            | `Optional[Union[AgentMemory, Memory]]` | `None` | Agent Memory                                                                                             |
| `enable_agentic_memory`             | `bool`                              | `False`   | Enable the agent to manage user memories using the Memory API                                            |
| `enable_user_memories`              | `bool`                              | `False`   | If True, the agent creates/updates user memories at the end of runs                                      |
| `add_memory_references`             | `Optional[bool]`                    | `None`    | If True, the agent adds a reference to user memories in the response                                     |
| `enable_session_summaries`          | `bool`                              | `False`   | If True, the agent creates/updates session summaries at the end of runs                                  |
| `add_session_summary_references`    | `Optional[bool]`                    | `None`    | If True, the agent adds a reference to session summaries in the response                                 |
| `add_history_to_messages`           | `bool`                              | `False`   | If True, add messages from the chat history to the messages list sent to the Model                       |
| `num_history_responses` (deprecated)| `Optional[int]`                     | `None`    | Deprecated in favor of `num_history_runs`                                                                |
| `num_history_runs`                  | `int`                               | `3`       | Number of historical runs to include in the messages                                                     |
| `knowledge`                         | `Optional[AgentKnowledge]`          | `None`    | Agent Knowledge                                                                                          |
| `add_references`                    | `bool`                              | `False`   | Enable RAG by adding references from AgentKnowledge to the user prompt                                   |
| `retriever`                         | `Optional[Callable[..., Optional[List[Dict]]]]` | `None` | Custom retrieval function to use instead of default search_knowledge                                      |
| `references_format`                 | `Literal["json","yaml"]`        | `json`    | Format of the references added to prompts                                                                |
| `storage`                           | `Optional[Storage]`                 | `None`    | Agent Storage                                                                                             |
| `extra_data`                        | `Optional[Dict[str, Any]]`          | `None`    | Extra data stored with this agent                                                                        |
| `tools`                             | `Optional[List[Union[Toolkit, Callable, Function, Dict]]]` | `None` | A list of tools provided to the Model                                                                    |
| `show_tool_calls`                   | `bool`                              | `True` if any tools are present, else `False` | Show tool calls in Agent response                                        |
| `tool_call_limit`                   | `Optional[int]`                     | `None`    | Maximum number of tool calls allowed                                                                     |
| `tool_choice`                       | `Optional[Union[str, Dict[str, Any]]]` | `None` | Controls which (if any) tool is called by the model                                                      |
| `reasoning`                         | `bool`                              | `False`   | Enable reasoning by working through the problem step by step                                              |
| `reasoning_model`                   | `Optional[Model]`                   | `None`    | Custom model for reasoning (chain-of-thought agent)                                                       |
| `reasoning_agent`                   | `Optional[Agent]`                   | `None`    | Custom Agent to perform reasoning steps                                                                  |
| `reasoning_min_steps`               | `int`                               | `1`       | Minimum number of reasoning steps                                                                        |
| `reasoning_max_steps`               | `int`                               | `10`      | Maximum number of reasoning steps                                                                        |
| `read_chat_history`                 | `bool`                              | `False`   | Add a tool that allows the Model to read the chat history                                                |
| `search_knowledge`                  | `bool`                              | `True`    | Add a tool that allows the Model to search the knowledge base                                            |
| `update_knowledge`                  | `bool`                              | `False`   | Add a tool that allows the Model to update the knowledge base                                            |
| `read_tool_call_history`            | `bool`                              | `False`   | Add a tool that allows the Model to get the tool call history                                            |
| `system_message`                    | `Optional[Union[str, Callable, Message]]` | `None` | Provide the system message as a string, function, or Message object                                      |
| `system_message_role`               | `str`                               | `system`  | Role for the system message                                                                              |
| `create_default_system_message`     | `bool`                              | `True`    | If False, the Agent will not generate a default system message                                           |
| `description`                       | `Optional[str]`                     | `None`    | Description of the Agent added at the start of the system message                                         |
| `goal`                              | `Optional[str]`                     | `None`    | Goal of the Agent task                                                                                   |
| `instructions`                      | `Optional[Union[str,List[str],Callable]]` | `None` | Instructions for the Agent (few-shot or templated)                                                       |
| `expected_output`                   | `Optional[str]`                     | `None`    | Provide an expected output example for structured prompts                                                |
| `additional_context`                | `Optional[str]`                     | `None`    | Additional context appended to the system message                                                        |
| `markdown`                          | `bool`                              | `False`   | If True, instruct the model to format its output in Markdown                                             |
| `add_name_to_instructions`          | `bool`                              | `False`   | If True, include the Agent name in the instructions                                                      |
| `add_datetime_to_instructions`      | `bool`                              | `False`   | If True, include the current datetime in the instructions                                                |
| `add_state_in_messages`             | `bool`                              | `False`   | If True, include session state variables in system/user messages                                         |
| `add_messages`                      | `Optional[List[Union[Dict,Message]]]` | `None`  | Extra messages inserted between system and user messages (e.g., few-shot examples)                       |
| `user_message`                      | `Optional[Union[List,Dict,str,Callable,Message]]` | `None` | Custom user message or template                                                                           |
| `user_message_role`                 | `str`                               | `user`    | Role for the user message                                                                                |
| `create_default_user_message`       | `bool`                              | `True`    | If False, the Agent will not generate a default user message                                             |
| `retries`                           | `int`                               | `0`       | Number of retry attempts on ModelProviderError                                                           |
| `delay_between_retries`             | `int`                               | `1`       | Delay (in seconds) between retries                                                                       |
| `exponential_backoff`               | `bool`                              | `False`   | If True, delay doubles after each retry                                                                  |
| `response_model`                    | `Optional[Type[BaseModel]]`         | `None`    | Pydantic model class to parse and validate responses                                                     |
| `parse_response`                    | `bool`                              | `True`    | If True, convert model output into `response_model`                                                      |
| `use_json_mode`                     | `bool`                              | `False`   | If True, use JSON schema mode instead of native structured outputs                                       |
| `save_response_to_file`             | `Optional[str]`                     | `None`    | File path template to save the agent’s final response                                                    |
| `stream`                            | `Optional[bool]`                    | `None`    | If True, stream responses; otherwise collect and return the final response                              |
| `stream_intermediate_steps`         | `bool`                              | `False`   | If True, stream intermediate reasoning or tool events                                                     |
| `team`                              | `Optional[List[Agent]]`             | `None`    | List of member Agents for delegation or collaboration                                                    |
| `team_data`                         | `Optional[Dict[str, Any]]`          | `None`    | Shared context data between team members                                                                  |
| `role`                              | `Optional[str]`                     | `None`    | Role label when this Agent is part of a team                                                             |
| `respond_directly`                  | `bool`                              | `False`   | If True, a member Agent will respond directly instead of returning to leader                             |
| `add_transfer_instructions`         | `bool`                              | `True`    | If True, include instructions for transferring tasks in system message                                   |
| `team_response_separator`           | `str`                               | `"\n"` | Separator string inserted between delegated Agent responses                                              |
| `debug_mode`                        | `bool`                              | `False`   | If True, enable debug-level logging and messages                                                         |
| `monitoring`                        | `bool`                              | `False`   | If True, send session and run telemetry to monitoring API                                                |
| `telemetry`                         | `bool`                              | `True`    | If True, collect minimal telemetry for analytics                                                         |
