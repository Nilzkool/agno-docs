## Parameters

| Parameter                        | Type                                           | Default | Description                                                          |
|----------------------------------|------------------------------------------------|---------|----------------------------------------------------------------------|
| `model`                          | `Optional[Model]`                              | `None`  | Model to use for this Agent                                          |
| `name`                           | `Optional[str]`                                | `None`  | Agent name                                                          |
| `agent_id`                       | `Optional[str]`                                | `None`  | Agent UUID (autogenerated if not set)                               |
| `introduction`                   | `Optional[str]`                                | `None`  | Agent introduction. This is added to the message history when a run is started. |
| `user_id`                        | `Optional[str]`                                | `None`  | Default user_id to use for this Agent                               |
| `session_id`                     | `Optional[str]`                                | `None`  | Session UUID (autogenerated if not set)                             |
| `session_name`                   | `Optional[str]`                                | `None`  | Session name                                                        |
| `session_state`                  | `Optional[Dict[str, Any]]`                     | `None`  | Session state (persisted across runs)                               |
| `context`                        | `Optional[Dict[str, Any]]`                     | `None`  | Context available for tools and prompt functions                    |
| `add_context`                    | `bool`                                         | `False` | If True, add the context to the user prompt                         |
| `resolve_context`                | `bool`                                         | `True`  | If True, resolve callable context entries before running            |
| `memory`                         | `Optional[Union[AgentMemory, Memory]]`         | `None`  | Agent Memory                                                        |
| `enable_agentic_memory`          | `bool`                                         | `False` | Enable the agent to manage user memories                            |
| `enable_user_memories`           | `bool`                                         | `False` | If True, create/update user memories after runs                     |
| `add_memory_references`          | `Optional[bool]`                               | `None`  | If True, include memory references in responses                     |
| `enable_session_summaries`       | `bool`                                         | `False` | If True, create/update session summaries after runs                 |
| `add_session_summary_references` | `Optional[bool]`                               | `None`  | If True, include session summary references in responses           |
| `add_history_to_messages`        | `bool`                                         | `False` | Add chat history to messages sent to the model                      |
| `num_history_responses`          | `Optional[int]`                                | `None`  | Deprecated in favor of `num_history_runs`                            |
| `num_history_runs`               | `int`                                          | `3`     | Number of historical runs to include in messages                    |
| `knowledge`                      | `Optional[AgentKnowledge]`                     | `None`  | Agent Knowledge                                                     |
| `add_references`                 | `bool`                                         | `False` | Enable RAG by adding knowledge references to the user prompt        |
| `retriever`                      | `Optional[Callable[..., Optional[List[Dict]]]]`| `None`  | Custom retrieval function for knowledge                             |
| `references_format`              | `Literal["json","yaml"]`                   | `"json"` | Format of the references                                            |
| `storage`                        | `Optional[Storage]`                            | `None`  | Agent Storage                                                       |
| `extra_data`                     | `Optional[Dict[str, Any]]`                     | `None`  | Extra data stored with this Agent                                   |
| `tools`                          | `Optional[List[Union[Toolkit,Callable,Function,Dict]]]` | `None`  | Tools provided to the model                                         |
| `show_tool_calls`                | `bool`                                         | `True`  | Show tool calls in Agent response                                   |
| `tool_call_limit`                | `Optional[int]`                                | `None`  | Maximum number of tool calls allowed                                |
| `tool_choice`                    | `Optional[Union[str,Dict[str,Any]]]`           | `None`  | Controls which tool is called by the model                          |
| `reasoning`                      | `bool`                                         | `False` | Enable step-by-step reasoning                                       |
| `reasoning_model`                | `Optional[Model]`                              | `None`  | Model to use for reasoning                                          |
| `reasoning_agent`                | `Optional[Agent]`                              | `None`  | Agent to orchestrate reasoning                                       |
| `reasoning_min_steps`            | `int`                                          | `1`     | Minimum reasoning steps                                             |
| `reasoning_max_steps`            | `int`                                          | `10`    | Maximum reasoning steps                                             |
| `read_chat_history`              | `bool`                                         | `False` | Add tool to read chat history                                       |
| `search_knowledge`               | `bool`                                         | `True`  | Add tool to search the knowledge base                               |
| `update_knowledge`               | `bool`                                         | `False` | Add tool to update the knowledge base                               |
| `read_tool_call_history`         | `bool`                                         | `False` | Add tool to retrieve tool call history                              |
| `system_message`                 | `Optional[Union[str,Callable,Message]]`        | `None`  | Custom system message                                              |
| `system_message_role`            | `str`                                          | `"system"` | Role for the system message                                         |
| `create_default_system_message`  | `bool`                                         | `True`  | Build default system message if none provided                       |
| `description`                    | `Optional[str]`                                | `None`  | Description added at start of system message                        |
| `goal`                           | `Optional[str]`                                | `None`  | Goal of this task                                                   |
| `instructions`                   | `Optional[Union[str,List[str],Callable]]`      | `None`  | Instructions for the Agent                                          |
| `expected_output`                | `Optional[str]`                                | `None`  | Expected output to guide the Agent                                  |
| `additional_context`             | `Optional[str]`                                | `None`  | Additional context appended to system message                       |
| `markdown`                       | `bool`                                         | `False` | If True, instruct model to use Markdown                             |
| `add_name_to_instructions`       | `bool`                                         | `False` | Add agent name to instructions                                      |
| `add_datetime_to_instructions`   | `bool`                                         | `False` | Add current datetime to instructions                                |
| `timezone_identifier`            | `Optional[str]`                                | `None`  | Custom timezone for datetime formatting                             |
| `add_state_in_messages`          | `bool`                                         | `False` | Embed session state variables in messages                           |
| `add_messages`                   | `Optional[List[Union[Dict,Message]]]`          | `None`  | Extra messages before user prompt                                   |
| `user_message`                   | `Optional[Union[List,Dict,str,Callable,Message]]` | `None` | Custom user message                                                |
| `user_message_role`              | `str`                                          | `"user"` | Role for the user message                                           |
| `create_default_user_message`    | `bool`                                         | `True`  | Build default user message if none provided                         |
| `retries`                        | `int`                                          | `0`     | Number of retry attempts                                            |
| `delay_between_retries`          | `int`                                          | `1`     | Delay between retries (seconds)                                     |
| `exponential_backoff`            | `bool`                                         | `False` | Double delay on each retry                                          |
| `response_model`                 | `Optional[Type[BaseModel]]`                    | `None`  | Pydantic model for structured output                                |
| `structured_outputs`             | `Optional[bool]`                               | `None`  | Use native structured outputs if supported                          |
| `parse_response`                 | `bool`                                         | `True`  | Parse the response into `response_model`                            |
| `use_json_mode`                  | `bool`                                         | `False` | Enforce JSON output mode for structured responses                   |
| `save_response_to_file`          | `Optional[str]`                                | `None`  | File path template to save responses                                |
| `stream`                         | `Optional[bool]`                               | `None`  | Stream the response                                                 |
| `stream_intermediate_steps`      | `bool`                                         | `False` | Stream reasoning and tool calls                                     |
| `team`                           | `Optional[List[Agent]]`                        | `None`  | Team of agents for task delegation                                  |
| `team_data`                      | `Optional[Dict[str, Any]]`                     | `None`  | Shared data across team members                                     |
| `role`                           | `Optional[str]`                                | `None`  | Role when this Agent is part of a team                              |
| `respond_directly`               | `bool`                                         | `False` | If True, member agent responds directly                             |
| `add_transfer_instructions`      | `bool`                                         | `True`  | Include instructions for task transfer                             |
| `team_response_separator`        | `str`                                          | `"\n"` | Separator between team member responses                             |
| `debug_mode`                     | `bool`                                         | `False` | Enable debug logs                                                   |
| `monitoring`                     | `bool`                                         | `False` | Log Agent data for monitoring                                       |
| `telemetry`                      | `bool`                                         | `True`  | Log minimal telemetry for analytics                                 |
