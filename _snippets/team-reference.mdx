## Parameters

| Parameter                         | Type                                       | Default                              | Description                                                                                      |
|-----------------------------------|--------------------------------------------|--------------------------------------|--------------------------------------------------------------------------------------------------|
| `members`                         | `List[Union[Agent, Team]]`                 | -                                    | List of agents or sub-teams comprising this team.                                                |
| `mode`                            | `Literal["route", "coordinate", "collaborate"]` | `"coordinate"`                     | Team operating mode.                                                                             |
| `model`                           | `Optional[Model]`                          | `None`                               | Model to use for the team leader.                                                                |
| `name`                            | `Optional[str]`                            | `None`                               | Name of the team.                                                                                |
| `team_id`                         | `Optional[str]`                            | `None`                               | Team UUID (autogenerated if not set).                                                            |
| `team_session_id`                 | `Optional[str]`                            | `None`                               | Session ID when this team is a member of a higher-level team.                                    |
| `role`                            | `Optional[str]`                            | `None`                               | Role of this team when it itself is a member of another team.                                   |
| `user_id`                         | `Optional[str]`                            | `None`                               | ID of the user interacting with this team.                                                       |
| `session_id`                      | `Optional[str]`                            | `None`                               | Session UUID (autogenerated if not set).                                                         |
| `session_name`                    | `Optional[str]`                            | `None`                               | Session name.                                                                                    |
| `session_state`                   | `Optional[Dict[str, Any]]`                 | `None`                               | Session state variables (persisted).                                                             |
| `add_state_in_messages`           | `bool`                                     | `False`                              | If True, interpolate session state into system and user messages.                               |
| `description`                     | `Optional[str]`                            | `None`                               | Description added at the start of the system message.                                            |
| `instructions`                    | `Optional[Union[str, List[str], Callable]]`| `None`                               | List of instructions for the team leader.                                                        |
| `expected_output`                 | `Optional[str]`                            | `None`                               | Expected output specification.                                                                   |
| `additional_context`              | `Optional[str]`                            | `None`                               | Additional context appended to the system message.                                               |
| `success_criteria`                | `Optional[str]`                            | `None`                               | Success criteria for terminating the run.                                                        |
| `markdown`                        | `bool`                                     | `False`                              | If True, instruct the model to format responses in Markdown.                                     |
| `add_datetime_to_instructions`    | `bool`                                     | `False`                              | If True, include current datetime in instructions.                                               |
| `add_member_tools_to_system_message` | `bool`                                 | `True`                               | If True, list available member tools in system prompt.                                           |
| `knowledge`                       | `Optional[AgentKnowledge]`                 | `None`                               | Knowledge base for retrieval-augmented generation.                                               |
| `retriever`                       | `Optional[Callable[..., Optional[List[Dict]]]]` | `None`                          | Custom retrieval function for references.                                                        |
| `references_format`               | `Literal["json","yaml"]`               | `"json"`                           | Format for knowledge references in prompts.                                                      |
| `context`                         | `Optional[Dict[str, Any]]`                 | `None`                               | User-supplied context dictionary.                                                                |
| `add_context`                     | `bool`                                     | `False`                              | If True, append `context` to the user prompt.                                                    |
| `enable_agentic_context`          | `bool`                                     | `False`                              | If True, enable updating and sharing a team‐level context tool.                                   |
| `share_member_interactions`       | `bool`                                     | `False`                              | If True, share past member interactions with each member.                                        |
| `get_member_information_tool`     | `bool`                                     | `False`                              | If True, add a tool to retrieve member details.                                                  |
| `search_knowledge`                | `bool`                                     | `True`                               | If True, add a tool to search the knowledge base.                                                |
| `show_tool_calls`                 | `bool`                                     | `True`                               | If True, include formatted tool-call output in responses.                                       |
| `tool_choice`                     | `Optional[Union[str, Dict[str, Any]]]`     | `None`                               | Controls which tool(s) the model may invoke (`"auto"`, `"none"`, or specific).              |
| `tool_call_limit`                 | `Optional[int]`                            | `None`                               | Maximum number of allowed tool calls per run.                                                    |
| `response_model`                  | `Optional[Type[BaseModel]]`                | `None`                               | Pydantic model for structured team responses.                                                    |
| `use_json_mode`                   | `bool`                                     | `False`                              | If True and `response_model` set, enforce JSON object output mode.                               |
| `parse_response`                  | `bool`                                     | `True`                               | If True, parse text responses into `response_model`.                                             |
| `memory`                          | `Optional[Memory]`                         | `None`                               | Team memory instance (shared across runs).                                                       |
| `enable_agentic_memory`           | `bool`                                     | `False`                              | If True, allow the team agent to update user memories.                                           |
| `enable_user_memories`            | `bool`                                     | `False`                              | If True, team agent creates/updates user memory after runs.                                      |
| `add_memory_references`           | `Optional[bool]`                           | `None`                               | If None, inferred from memory settings; else explicitly include memory refs in prompts.          |
| `enable_session_summaries`        | `bool`                                     | `False`                              | If True, generate session summaries at the end of runs.                                          |
| `add_session_summary_references`  | `Optional[bool]`                           | `None`                               | If None, inferred; else explicitly include summaries in prompts.                                 |
| `enable_team_history`             | `bool`                                     | `False`                              | If True, include prior team chat history in prompts.                                            |
| `num_of_interactions_from_history`| `Optional[int]`                            | `None`                               | Deprecated alias; if set, overrides `num_history_runs`.                                         |
| `num_history_runs`                | `int`                                      | `3`                                  | Number of past interactions to retrieve for history.                                             |
| `storage`                         | `Optional[Storage]`                        | `None`                               | Storage backend for session persistence.                                                        |
| `extra_data`                      | `Optional[Dict[str, Any]]`                 | `None`                               | Arbitrary extra metadata stored with the team.                                                   |
| `debug_mode`                      | `bool`                                     | `False`                              | If True, enable debug logging for the team and members.                                         |
| `show_members_responses`          | `bool`                                     | `False`                              | If True, display sub-team/member responses in output panels.                                     |
| `monitoring`                      | `bool`                                     | `False`                              | If True, emit monitoring telemetry to agno.com.                                                  |
| `telemetry`                       | `bool`                                     | `True`                               | If True, log minimal telemetry for analytics.                                                   |
