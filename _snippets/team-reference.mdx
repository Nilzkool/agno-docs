| Parameter                                | Type                                      | Default   | Description                                                         |

| `references_format`                      | `Literal["json", "yaml"]`             | `"json"`| Format of knowledge references                                      |

| `share_member_interactions`              | `bool`                                    | `False`   | If True, share past member interactions                             |
| `read_team_history`                      | `bool`                                    | `False`   | If True, include previous team chat history                         |
| `search_knowledge`                       | `bool`                                    | `True`    | If True, add a tool to search the knowledge base                   |
| `get_member_information_tool`            | `bool`                                    | `False`   | If True, add tool to fetch member information                       |
| `show_tool_calls`                        | `bool`                                    | `True`    | If True, display tool calls in team response                       |
| `tool_call_limit`                        | `Optional[int]`                           | `None`    | Maximum number of tool calls allowed                                |
| `tool_choice`                            | `Optional[Union[str, Dict[str, Any]]]`    | `None`    | Controls which tool the model may use                               |
| `response_model`                         | `Optional[Type[BaseModel]]`               | `None`    | Pydantic model for structured outputs                               |
| `use_json_mode`                          | `bool`                                    | `False`   | If True, force JSON mode with `response_model`                      |
| `parse_response`                         | `bool`                                    | `True`    | If True, parse model response into `response_model`                |
| `memory`                                 | `Optional[Union[TeamMemory, Memory]]`     | `None`    | Memory backend for team                                             |

| `add_memory_references`                  | `Optional[bool]`                          | `None`    | If True, include memory references in responses                    |

| `num_of_interactions_from_history`       | `Optional[int]`                           | `None`    | Deprecated; use `num_history_runs`                                  |

| `reasoning`                              | `bool`                                    | `False`   | If True, run reasoning steps before model call                     |

| `storage`                                | `Optional[Storage]`                       | `None`    | Storage backend for team sessions                                   |
| `extra_data`                             | `Optional[Dict[str, Any]]`                | `None`    | Extra data persisted with this team                                 |
| `debug_mode`                             | `bool`                                    | `False`   | If True, enable debug logging                                       |
| `show_members_responses`                 | `bool`                                    | `False`   | If True, display member responses in logs                          |
| `monitoring`                             | `bool`                                    | `False`   | If True, send monitoring data to agno.com                          |
| `telemetry`                              | `bool`                                    | `True`    | If True, collect minimal telemetry for analytics                    |
