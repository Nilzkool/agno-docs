The `TogetherEmbedder` class can be used to embed text data into vectors using the Together API. Together follows the OpenAI API specification, so `TogetherEmbedder` extends `OpenAIEmbedder` with adjustments for Together's endpoints. Get your key from [here](https://api.together.xyz/settings/api-keys).

## Usage

```python
from agno.embedder.together import TogetherEmbedder
from agno.agent import AgentKnowledge
from agno.vectordb.pgvector import PgVector

# Embed a sentence
embeddings = TogetherEmbedder().get_embedding("The quick brown fox jumps over the lazy dog.")

# Print the embeddings and their dimensionality
print(f"Embeddings: {embeddings[:5]}")
print(f"Dimensions: {len(embeddings)}")

# Use an embedder in a knowledge base
knowledge_base = AgentKnowledge(
    vector_db=PgVector(
        db_url="postgresql+psycopg://ai:ai@localhost:5532/ai",
        table_name="together_embeddings",
        embedder=TogetherEmbedder(),
    ),
    num_documents=2,
)
```

## Params

| Parameter         | Type                        | Default                                       | Description                                                 |
| ----------------- | --------------------------- | --------------------------------------------- | ----------------------------------------------------------- |
| `id`              | `str`                       | `"togethercomputer/m2-bert-80M-32k-retrieval"` | The Together model ID for embeddings                        |
| `dimensions`      | `int`                       | `768`                                         | The dimensionality of the embeddings                        |
| `api_key`         | `str`                       | `None`                                        | API key for authenticating requests                         |
| `base_url`        | `str`                       | `"https://api.together.xyz/v1"`              | The base URL for the Together embeddings endpoint           |
| `request_params`  | `Optional[Dict[str, Any]]`  | `None`                                        | Additional parameters to include in the API request         |
| `client_params`   | `Optional[Dict[str, Any]]`  | `None`                                        | Extra client configuration parameters                       |
