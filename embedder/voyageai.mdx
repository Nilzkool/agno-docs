The `VoyageAIEmbedder` class is used to embed text data into vectors using the Voyage AI API. Get your key from [here](https://dash.voyageai.com/api-keys).

## Usage

```python
from agno.embedder.voyageai import VoyageAIEmbedder
from agno.agent import AgentKnowledge
from agno.vectordb.pgvector import PgVector

# Embed a sentence
embeddings = VoyageAIEmbedder().get_embedding("The quick brown fox jumps over the lazy dog.")

# Print the embeddings and their dimensionality
print(f"Embeddings: {embeddings[:5]}")
print(f"Dimensions: {len(embeddings)}")

# Use an embedder in a knowledge base
knowledge_base = AgentKnowledge(
    vector_db=PgVector(
        db_url="postgresql+psycopg://ai:ai@localhost:5532/ai",
        table_name="voyageai_embeddings",
        embedder=VoyageAIEmbedder(),
    ),
    num_documents=2,
)
```

## Params

| Parameter        | Type                       | Default                                     | Description                                                      |
| ---------------- | -------------------------- | ------------------------------------------- | ---------------------------------------------------------------- |
| `id`             | `str`                      | `"voyage-2"`                              | The model ID used for generating embeddings                      |
| `dimensions`     | `int`                      | `1024`                                      | The dimensionality of the embeddings                             |
| `request_params` | `Optional[Dict[str, Any]]` | `None`                                      | Additional parameters to include in the API request              |
| `api_key`        | `str`                      | `None`                                      | API key for authenticating requests                              |
| `max_retries`    | `Optional[int]`            | `None`                                      | Maximum number of retries for API requests                       |
| `timeout`        | `Optional[float]`          | `None`                                      | Timeout duration for API requests                                |
| `client_params`  | `Optional[Dict[str, Any]]` | `None`                                      | Extra parameters for configuring the client                      |
| `base_url`       | `str`                      | `"https://api.voyageai.com/v1/embeddings"` | The base URL for the API endpoint                                |
| `voyage_client`  | `Optional[Client]`         | `None`                                      | Preconfigured client instance to use for requests                |
