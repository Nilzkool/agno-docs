---
title: Sessions
---

When we call `Agent.run()`, it creates a stateless, singular Agent run and generates a new `session_id` if one isn't provided.

But what if we want to continue this run—i.e., have a multi-turn conversation? That's where sessions come in. A session is a collection of consecutive runs.

In practice, a session is a multi-turn conversation between a user and an Agent. Using a `session_id`, we can connect the conversation history and state across multiple runs.

Let's outline some key concepts:

- **Session:** A session is a collection of consecutive runs, like a multi-turn conversation between a user and an Agent. Sessions are identified by a `session_id`, and each turn is a **run**.
- **Run:** Every interaction (i.e., chat or turn) with an Agent is called a **run**. Runs are identified by a `run_id`, and calling `Agent.run()` generates a new `run_id` (and a `session_id` if not provided).
- **Messages:** Individual messages sent between the Agent and the model. Messages form the communication protocol for each run.

## Single-turn example

Below is an example where a single run is created with an Agent. A `run_id` and a new `session_id` are generated automatically because we didn't provide one.

```python
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.utils.pprint import pprint_run_response

agent = Agent(model=OpenAIChat(id="gpt-4o-mini"))

# Run the agent and return the RunResponse
run_response = agent.run("Tell me a 5 second short story about a robot")
# Pretty-print the response
pprint_run_response(run_response)
```

## Multi-user, multi-session Agents

Each user interacting with an Agent gets a unique set of sessions, and you can have multiple users interacting with the same Agent concurrently.

Set a `user_id` to connect a user to their sessions with the Agent.

In the example below, we set both `user_id` and `session_id` to demo how to have multi-turn conversations with multiple users simultaneously. In production, the `session_id` will usually be auto-generated by the Agent.

<Note>

Multi-user, multi-session currently only works with `Memory.v2`, which is the default memory implementation in this version.

</Note>

```python
from agno.agent import Agent
from agno.models.openai import OpenAIChat
from agno.memory.v2 import Memory

agent = Agent(
    model=OpenAIChat(id="gpt-4o-mini"),
    memory=Memory(),
    add_history_to_messages=True,
    num_history_runs=3,
)

user_1_id = "user_101"
user_2_id = "user_102"

user_1_session_id = "session_101"
user_2_session_id = "session_102"

# Start the session with user 1
run1 = agent.run(
    "Tell me a 5 second short story about a robot.",
    user_id=user_1_id,
    session_id=user_1_session_id,
)
pprint_run_response(run1)

# Continue the session with user 1
run2 = agent.run(
    "Now tell me a joke.",
    user_id=user_1_id,
    session_id=user_1_session_id,
)
pprint_run_response(run2)

# Start the session with user 2
run3 = agent.run(
    "Tell me about quantum physics.",
    user_id=user_2_id,
    session_id=user_2_session_id,
)
pprint_run_response(run3)

# Continue the session with user 2
run4 = agent.run(
    "What is the speed of light?",
    user_id=user_2_id,
    session_id=user_2_session_id,
)
pprint_run_response(run4)

# Ask the agent to give a summary of the conversation for user 1
summary = agent.run(
    "Give me a summary of our conversation.",
    user_id=user_1_id,
    session_id=user_1_session_id,
)
pprint_run_response(summary)
```
