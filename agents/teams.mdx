Orchestrate multiple Agents using the `Team` class. Teams allow you to coordinate, route, or collaborate across member agents to solve complex tasks.

Import and create a Team:

```python
from agno.agent import Agent
from agno.team.team import Team
from agno.models.openai import OpenAIChat
from agno.tools.duckduckgo import DuckDuckGoTools
from agno.tools.hackernews import HackerNewsTools

# Define member agents
researcher = Agent(
    name="Researcher",
    model=OpenAIChat("gpt-4o"),
    role="Research information",
    tools=[DuckDuckGoTools(cache_results=True)],
)

writer = Agent(
    name="Writer",
    model=OpenAIChat("gpt-4o"),
    role="Write content based on research",
)

# Create a coordinating team
team = Team(
    members=[researcher, writer],
    mode="coordinate",            # route | coordinate | collaborate
    model=OpenAIChat("gpt-4o"),
    name="Content Team",
    instructions=[
        "First, have the Researcher gather information on the topic.",
        "Then, have the Writer create content based on the research.",
    ],
)

# Run the team
response = team.run("Write a short article about climate change solutions")
print(response.content)
```

## Modes of operation

- **route**: Forward or hand off tasks to a specific member.
- **coordinate**: Analyze and transfer tasks based on member roles.
- **collaborate**: Run all members and synthesize a combined answer.

### Collaborate Example

```python
from pydantic import BaseModel

class DebateResult(BaseModel):
    topic: str
    perspective_one: str
    perspective_two: str
    conclusion: str

# Two perspective agents
a1 = Agent(name="P1", model=OpenAIChat("gpt-4o"), role="First perspective provider")
a2 = Agent(name="P2", model=OpenAIChat("gpt-4o"), role="Second perspective provider")

team = Team(
    members=[a1, a2],
    mode="collaborate",
    model=OpenAIChat("gpt-4o"),
    name="Debate Team",
    instructions=[
        "Have both agents provide their perspectives on the topic.",
        "Synthesize into a balanced conclusion.",
    ],
    response_model=DebateResult,
)

result = team.run("Is AGI possible in the next decade?")
print(result.content)
```
