We prompt Agents using `description`, `instructions`, and a number of other settings. These settings are used to build the **system** message that is sent to the language model.

Understanding how these prompts are created will help you build better Agents.

The 2 key parameters are:

1. **Description**: A description that guides the overall behaviour of the agent.
2. **Instructions**: A list of precise, task-specific instructions on how to achieve its goal.

<Note>
  Description and instructions only provide a formatting benefit, we do not alter or abstract any information and you can always set the `system_message` to provide your own system prompt.
</Note>

## System message

The system message is created using `description`, `goal`, `instructions`, and a number of other settings. The `description` is added to the start of the system message, `<your_goal>` is used when `goal` is set, and `instructions` are added as a list after `<instructions>`. For example:

```python instructions.py
from agno.agent import Agent

agent = Agent(
    description="You are a famous short story writer asked to write for a magazine",
    goal="Write a suspenseful horror scene in exactly two sentences.",
    instructions=["Focus on atmosphere and tension."],
    markdown=True,
    debug_mode=True,
)
agent.print_response("Tell me a 2 sentence horror story.", stream=True)
```

Will translate to (set `debug_mode=True` to view the logs):

```js
DEBUG    ============== system ==============
DEBUG    You are a famous short story writer asked to write for a magazine

         <your_goal>
         Write a suspenseful horror scene in exactly two sentences.
         </your_goal>

         ## Instructions
         - Focus on atmosphere and tension.
         - Use markdown to format your answers.
DEBUG    ============== user ==============
DEBUG    Tell me a 2 sentence horror story.
...
```

## Set the system message directly

You can manually set the system message using the `system_message` parameter.

```python
from agno.agent import Agent

agent = Agent(system_message="Share a 2 sentence story about")
agent.print_response("Love in the year 12000.")
```

<Tip>
Some models via some model providers, like `llama-3.2-11b-vision-preview` on Groq, require no system message. To remove the system message, set `create_default_system_message=False` and `system_message=None`. Additionally, if `markdown=True` is set, it will add a system message, so either remove it or explicitly disable the system message.
</Tip>

## Default system message

The Agent creates a default system message that can be customized using the following parameters:

| Parameter                        | Type                   | Default  | Description                                                                                                                                               |
|----------------------------------|------------------------|----------|-----------------------------------------------------------------------------------------------------------------------------------------------------------|
| `description`                    | `str`                  | `None`   | A description of the Agent that is added to the start of the system message.                                                                             |
| `goal`                           | `str`                  | `None`   | Describe the task the agent should achieve. Wrapped in `<your_goal>` tags.                                                                                 |
| `instructions`                   | `List[str]`            | `None`   | List of instructions added to the system prompt in `<instructions>` tags.                                                                                 |
| `expected_output`                | `str`                  | `None`   | Provide the expected output from the Agent. Added at the end in `<expected_output>` tags.                                                                 |
| `additional_context`             | `str`                  | `None`   | Additional context appended to the end of the system message.                                                                                              |
| `markdown`                       | `bool`                 | `False`  | If `True` and no `response_model`, adds an instruction to format output using markdown.                                                                    |
| `add_datetime_to_instructions`   | `bool`                 | `False`  | If `True`, add the current datetime to the `<additional_information>` section.                                                                             |
| `create_default_system_message`  | `bool`                 | `True`   | If `False`, no system message is built unless `system_message` is set.                                                                                     |
| `system_message`                 | `str` 
`Callable`      | `None`   | Provide your own system prompt directly.                                                                                                                |
| `system_message_role`            | `str`                  | `"system"` | Role for the system message.                                                                                                                               |
| `add_state_in_messages`          | `bool`                 | `False`  | If `True`, variables from `session_state`, `context`, and `extra_data` are formatted into the messages.                                                    |

<Tip>
Disable the default system message by setting `create_default_system_message=False`.
</Tip>

## User message

The input `message` sent to the `Agent.run()` or `Agent.print_response()` functions is used as the user message.

## Default user message

The Agent creates a default user message, which includes the input message plus optional context or references. The default user message can be customized using:

| Parameter                        | Type                             | Default   | Description                                                                                                                           |
|----------------------------------|----------------------------------|-----------|---------------------------------------------------------------------------------------------------------------------------------------|
| `context`                        | `Dict[str, Any]`                 | `None`    | Additional context used to format the user message when `add_context=True`.                                                          |
| `add_context`                    | `bool`                           | `False`   | If `True`, appends `context` in `<context>` tags.                                                                                     |
| `resolve_context`                | `bool`                           | `True`    | If `True`, call any functions in `context` before adding it to the prompt.                                                           |
| `add_references`                 | `bool`                           | `False`   | If `True`, retrieves knowledge base references via `retriever` and appends in `<references>` tags.                                   |
| `retriever`                      | `Callable`                       | `None`    | Function to get references when `add_references=True`.                                                                                |
| `references_format`              | `Literal["json","yaml"]`     | `
