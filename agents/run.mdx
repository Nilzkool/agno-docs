---
title: Agent.run()
---

The `Agent.run()` function runs the agent and generates a response, either as a `RunResponse` object or a stream of `RunResponse` objects.

Many of our examples use `agent.print_response()` which is a helper utility to print the response in the terminal. It uses `agent.run()` under the hood.

Here's how to run your agent. The response is captured in the `response` and `response_stream` variables.

```python
from typing import Iterator
from agno.agent import Agent, RunResponse
from agno.models.openai import OpenAIChat
from agno.utils.pprint import pprint_run_response

agent = Agent(model=OpenAIChat(id="gpt-4o-mini"))

# Run agent and return the response as a variable
response: RunResponse = agent.run("Tell me a 5 second short story about a robot")
# Run agent and return the response as a stream
response_stream: Iterator[RunResponse] = agent.run("Tell me a 5 second short story about a lion", stream=True)

# Print the response in markdown format
pprint_run_response(response, markdown=True)
# Print the response stream in markdown format
pprint_run_response(response_stream, markdown=True)
```

<Note>Set `stream=True` to return a stream of `RunResponse` objects.</Note>

## RunResponse

The `Agent.run()` function returns either a `RunResponse` object or an `Iterator<RunResponse>` when `stream=True`. It has the following attributes:

### RunResponse Attributes

| Attribute              | Type                             | Default                        | Description                                                                                                           |
| ---------------------- | -------------------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| `content`              | `Any`                            | `None`                         | The response content.                                                                                                 |
| `content_type`         | `str`                            | `"str"`                      | Specifies the data type of the content.                                                                               |
| `thinking`             | `Optional[str]`                  | `None`                         | Internal "thinking" text (e.g., model's chain-of-thought).                                                          |
| `reasoning_content`    | `Optional[str]`                  | `None`                         | Aggregated reasoning steps content produced when `stream_intermediate_steps=True`.                                    |
| `event`                | `str`                            | `RunEvent.run_response.value`  | The event type of this `RunResponse` (e.g., `RunStarted`, `RunResponse`, etc.).                                      |
| `messages`             | `Optional[List[Message]]`        | `None`                         | List of messages included in the run (system, user, history, etc.).                                                   |
| `metrics`              | `Optional[Dict[str, Any]]`       | `None`                         | Usage metrics for this run (tokens, time, etc.).                                                                     |
| `model`                | `Optional[str]`                  | `None`                         | ID of the model used for this run.                                                                                    |
| `run_id`               | `Optional[str]`                  | `None`                         | Unique identifier for this run.                                                                                       |
| `agent_id`             | `Optional[str]`                  | `None`                         | Identifier of the agent that ran.                                                                                     |
| `session_id`           | `Optional[str]`                  | `None`                         | Identifier of the session.                                                                                            |
| `workflow_id`          | `Optional[str]`                  | `None`                         | Identifier of an associated workflow (if any).                                                                        |
| `tools`                | `Optional[List[Dict[str, Any]]]` | `None`                         | Tools provided to the model for this run.                                                                             |
| `formatted_tool_calls` | `Optional[List[str]]`            | `None`                         | Human-readable descriptions of the tool calls made by the model.                                                      |
| `images`               | `Optional[List[ImageArtifact]]`  | `None`                         | Images generated or returned by the model.                                                                            |
| `videos`               | `Optional[List[VideoArtifact]]`  | `None`                         | Videos generated or returned by the model.                                                                            |
| `audio`                | `Optional[List[AudioArtifact]]`  | `None`                         | Audio artifacts generated or returned by the model.                                                                   |
| `response_audio`       | `Optional[AudioResponse]`        | `None`                         | The raw audio response from the model.                                                                                |
| `citations`            | `Optional[Citations]`            | `None`                         | Citations or references included from knowledge retrieval.                                                            |
| `extra_data`           | `Optional[RunResponseExtraData]` | `None`                         | Additional data such as references, extra messages, reasoning steps, and reasoning messages.                         |
| `created_at`           | `int`                            | current timestamp             | Unix timestamp when the response was created.                                                                         |
