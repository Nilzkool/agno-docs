---
title: Agent.run()
---

The `Agent.run()` function runs the agent and generates a response, either as a `RunResponse` object or a stream of `RunResponse` objects.

Many of our examples use `agent.print_response()` which is a helper utility to print the response in the terminal. It uses `agent.run()` under the hood.

Here's how to run your agent. The response is captured in the `response` and `response_stream` variables.

```python
from typing import Iterator
from agno.agent import Agent, RunResponse
from agno.models.openai import OpenAIChat
from agno.utils.pprint import pprint_run_response

agent = Agent(model=OpenAIChat(id="gpt-4o-mini"))

# Run agent and return the response as a variable
response: RunResponse = agent.run("Tell me a 5 second short story about a robot")
# Run agent and return the response as a stream
response_stream: Iterator[RunResponse] = agent.run(
    "Tell me a 5 second short story about a lion", stream=True
)

# Print the response in markdown format
pprint_run_response(response, markdown=True)
# Print the response stream in markdown format
pprint_run_response(response_stream, markdown=True)
```

<Note>Set `stream=True` to return a stream of `RunResponse` objects.</Note>

## RunResponse

The `Agent.run()` function returns either a `RunResponse` object or an `Iterator[RunResponse]` when `stream=True`. It has the following attributes:

### RunResponse Attributes

| Attribute             | Type                             | Default                        | Description                                                                                                     |
| --------------------- | -------------------------------- | ------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `content`             | `Any`                            | `None`                         | Content of the response.                                                                                        |
| `content_type`        | `str`                            | `"str"`                      | Specifies the data type of the content.                                                                         |
| `thinking`            | `Optional[str]`                  | `None`                         | Interim thinking or internal process of the agent.                                                              |
| `reasoning_content`   | `Optional[str]`                  | `None`                         | Combined reasoning steps content.                                                                               |
| `event`               | `str`                            | `RunEvent.run_response.value`  | Event type of the response.                                                                                     |
| `messages`            | `Optional[List[Message]]`        | `None`                         | List of messages included in the response.                                                                      |
| `metrics`             | `Optional[Dict[str, Any]]`       | `None`                         | Usage metrics of the run.                                                                                       |
| `model`               | `Optional[str]`                  | `None`                         | Model id used in the run.                                                                                       |
| `run_id`              | `Optional[str]`                  | `None`                         | Unique run identifier.                                                                                          |
| `agent_id`            | `Optional[str]`                  | `None`                         | Agent identifier.                                                                                               |
| `session_id`          | `Optional[str]`                  | `None`                         | Session identifier.                                                                                             |
| `workflow_id`         | `Optional[str]`                  | `None`                         | Workflow identifier if run within a workflow.                                                                   |
| `tools`               | `Optional[List[Dict[str, Any]]]` | `None`                         | List of tools provided to the model.                                                                            |
| `formatted_tool_calls`| `Optional[List[str]]`            | `None`                         | Formatted summaries of tool calls made during the run.                                                          |
| `images`              | `Optional[List[ImageArtifact]]`  | `None`                         | Images produced by the model.                                                                                   |
| `videos`              | `Optional[List[VideoArtifact]]`  | `None`                         | Videos produced by the model.                                                                                   |
| `audio`               | `Optional[List[AudioArtifact]]`  | `None`                         | Audio artifacts produced by the model.                                                                          |
| `response_audio`      | `Optional[AudioResponse]`        | `None`                         | Model's raw audio response.                                                                                     |
| `citations`           | `Optional[Citations]`            | `None`                         | References and citations returned by the model.                                                                 |
| `extra_data`          | `Optional[RunResponseExtraData]` | `None`                         | Extra structured data: references, added messages, reasoning steps, and reasoning messages.                     |
| `created_at`          | `int`                            | Unix timestamp (time of run)   | Unix timestamp when the response was created.                                                                   |
